# Spec Delta

## ADDED Requirements

### Requirement: 既有文档受检替换与实际写入事实

已有普通文档的替换 MUST 绑定冻结字节、目标身份及刚核验的磁盘版本；写入 MUST 经过同目录独占临时文件、完整写入和文件同步，再执行平台受检替换及该平台要求的目录同步/权限处理。替换发生前的失败 MUST 保留原文件、调用方内存和可恢复材料；替换发生后的失败 MUST 保留内存、恢复材料和已写入事实，明确保证不足。MUST NOT 先删原文件、原地截断或静默回退为非原子写。结果 MUST 表达实际写入事实及平台保证范围，MUST NOT 将写前检查称为跨进程 CAS。关联 SAFE-01～07、R-15-07/13、V-08。

#### Scenario: 冻结字节成功替换

- **WHEN** 目标身份和磁盘版本符合请求且平台受检替换成功
- **THEN** 返回实际写出的目标、版本和完整字节事实，供宿主结算；原有 create-only 入口继续拒绝覆盖已有目标

#### Scenario: 目标发生外部变化

- **WHEN** 临时写入前或发布前发现磁盘身份/内容版本已变化
- **THEN** 明确返回冲突，保留原目标和内存，不用旧确认覆盖新版本

#### Scenario: 任一写入阶段失败

- **WHEN** 临时文件创建、部分写、文件同步、权限处理或替换失败
- **THEN** 返回阶段和可恢复结果，不发布伪成功基线，不删除原目标或恢复材料；若替换已发生但后续目录同步失败，保留该实际写入事实与保证不足，不能声称目标未变

#### Scenario: 权限复制能力不支持

- **WHEN** 权限复制明确返回不支持且该平台临时文件创建和替换安全访问语义已有证据
- **THEN** 仅按 WC-04 的具体范围继续并说明保证；其他权限失败停止，mode 不被当作 ACL/xattr 已完整保全的证明
