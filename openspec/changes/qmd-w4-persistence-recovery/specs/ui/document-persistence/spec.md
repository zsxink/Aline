# Spec Delta

## Purpose

为 M2 单文档编辑提供可检查的保存、外部冲突、可撤销重载和异常恢复行为，保护最新输入与临时资源，明确成功版本、失败保全和真实平台证据边界，不能用只读阶段或无头原语推定安全闭环已通过。

## ADDED Requirements

### Requirement: 保存状态依据实际内容和写入事实

界面 MUST 区分未修改、有修改、保存中和保存失败。保存 MUST 包含当前打开块最新内容且不改变输入分组或历史；成功 MUST 只登记实际写入快照。dirty MUST 依据当前内容相对实际保存基线的等价事实，不依赖历史深度、revision 或粘性编辑标记。关联 SAFE-04/05、TA-01、AC-05。

#### Scenario: 保存中继续输入

- **WHEN** 较早快照保存成功时当前输入已继续变化
- **THEN** 登记实际保存的内容和目标，较新内容仍显示有修改；旧失败回执不覆盖较新成功，旧路径结果不更新新路径

#### Scenario: 撤销回保存内容

- **WHEN** 当前内容确实回到实际保存基线
- **THEN** 恢复未修改状态；相同历史深度但不同内容仍为有修改

### Requirement: 自动保存与恢复使用独立路径

默认自动保存 MUST 对已有路径且有修改的文档在停止输入 1 秒后防抖执行；组合期延后，未命名文档不自动选路径。每 10 秒的恢复快照 MUST 使用应用管理的独立目标，包含当前输入及临时图片引用，不代替自动保存。关联 SAFE-04/08、ED-01。

#### Scenario: 组合期间显式请求

- **WHEN** 组合未结束时用户手动保存或另存为
- **THEN** 提供可取消等待；平台自然确认或取消后才取当前快照，取消请求不改变输入/历史、不提前写候选；实际执行时重验目标/磁盘/资源身份

#### Scenario: 恢复写入失败

- **WHEN** 用户文档保存或独立恢复写入失败
- **THEN** 分别反馈各自状态，保留内存、原文件及旧恢复材料，不把旧恢复记录说成已保护最新输入

### Requirement: 外改冲突与重载可撤销

聚焦和任何写盘前 MUST 检查外部变化，mtime/size 只作快筛。本地无修改时自动重载，有本地修改时 MUST 暂停自动保存并提供基线/本地/磁盘差异及载入磁盘、确认覆盖、另存为、取消。两种载入磁盘路径 MUST 建可撤销历史边界，磁盘基线不随 Undo/Redo 回退。关联 SAFE-07、TA-02、AC-06。

#### Scenario: 同尺寸同时间戳外改

- **WHEN** 外部内容变化但 mtime/size 保持相同，或覆盖确认后目标再次变化
- **THEN** 内容版本检查发现变化并进入或重新进入冲突，不丢草稿、不覆盖未经确认的新内容

#### Scenario: 重载后撤销或重做

- **WHEN** 自动或显式重载后 Undo 恢复旧内容，再 Redo 回磁盘内容
- **THEN** Undo 只改内存/选区，按新磁盘基线判脏、提示来源并暂停自动保存；Redo 回基线恢复未修改和正常策略，之后保存仍检查外改

#### Scenario: 文件删除或不可读

- **WHEN** 原文档被删除或读取失败
- **THEN** 保留内存和恢复材料并反馈重试/另存为，不当作普通空文件

### Requirement: 恢复资源和关闭保护不得早清理

恢复 MUST 逐文档提供恢复/丢弃，先入内存且不覆盖磁盘，不提供全部丢弃。当前/历史/恢复/在途任务仍引用的临时图片 MUST 保留；资源齐备后才发布恢复记录。关闭入口 MUST 共享保存/放弃/取消保护，不得通过窗口销毁丢弃实际写盘回执。关联 SAFE-08、IMAGE-07/08、AC-10、R-6-06/15-08～12。

#### Scenario: 异常恢复与损坏条目

- **WHEN** 启动时存在有效恢复记录及一个损坏条目
- **THEN** 有效记录可独立恢复且临时图片可读，原磁盘不变；损坏条目隔离反馈不影响其他条目

#### Scenario: 保存失败或取消关闭

- **WHEN** 关闭中保存失败、冲突未解决或用户取消
- **THEN** 保留文档输入、选区、历史和恢复资源；尚未结算写盘继续按实际身份结算，不提前显示成功或删除材料
