# Spec Delta

## Purpose

为 M0 无头消费方提供携带源码来源的语义展示结果、块与间隙、受保护区间及坐标转换，使展示投影始终可追溯到同一源码快照，失败和超限时仍保留原文及安全编辑入口。

## ADDED Requirements

### Requirement: 解析来源与块覆盖

解析 MUST 仅从不可变源码派生；改写只作用解析副本并完整追溯来源。块 MUST 排除尾分隔，块与显式间隙 MUST 无遗漏无重叠覆盖源码。关联 MD-01～06、E3/E5、K-02。

#### Scenario: 展示树可检查

- **WHEN** 输入含嵌套块、空行、无尾换行、Front matter 与代码字面区
- **THEN** 可 dump 展示树、原始范围、块/Gap、诊断；公式/emoji 扫描避让字面区，完整配对文首围栏才识别 Front matter

#### Scenario: 合成与多阶段改写

- **WHEN** 解析事件跨多个改写片段或输入包含真实控制字节
- **THEN** 结果保留每段来源/合成锚点；无法证明映射时回原文，不把改写偏移当源码或发生 stand-in 碰撞吞字

#### Scenario: 配置与旧结果

- **WHEN** 输入版本或解析配置已经变化后返回旧解析结果
- **THEN** 产物携带原输入身份，不成为当前编辑权限或映射依据

### Requirement: 映射精确性与 Unicode 边界

跨源码/绘制/UTF-16 转换 MUST 验证版本、投影、边界及方向，返回来源范围及精确性。原样段精确往返，对齐幂等，非双射关系保持规范锚点稳定。关联 EDIT-04、AC-03 基础、E5、S-5。

#### Scenario: 实体隐藏与合成

- **WHEN** 转换转义、&amp;、多字符实体、隐藏标签/目标或合成换行的坐标
- **THEN** 实体点击锚点归实体起点；编辑覆盖使用完整来源；Hidden/Synthetic 不冒充精确删除范围，不要求每个源码字节严格互逆

#### Scenario: 非法投影端点

- **WHEN** 传入 emoji 代理对中间、UTF-8 半字符、越界或旧投影坐标
- **THEN** 返回明确错误，不 clamp 成可执行删除、不 panic；正反向选区方向不丢失

#### Scenario: 重复文字与字素

- **WHEN** 在完整的 Source identity 投影或 Visual 解析投影上，按 Unicode17 查询前进/后退字素边界，输入含重复空白、中文、组合附加符、emoji ZWJ、区域指示符或 Indic 连字
- **THEN** 查询使用绑定该 Projection 的受检 `DrawnOffset`；字素边界与 Unicode scalar/UTF-16 代理对边界分别验证，来源定位仍经 `source_at`/`drawn_at`，不使用字符相等回搜；无效起点、旧投影及超出每次查询 4096 UTF-8 字节供给预算时返回类型化错误，不猜测或返回偏移

#### Scenario: 字素规则版本与上下文预算

- **WHEN** 查询长 RI 上下文、超长组合簇，或 Unicode17/Unicode18 有差异的 `U+094D U+0915`
- **THEN** 每块供给最多 256 字节，含 `PreContext` 回扫的累计供给字节超过 4096 时返回 `ScanBudgetExceeded` 且不返回边界；Unicode17 基线将该 Indic 样本的 UTF-8 字节边界报告为 `[0,3,6]`，并明确不同于 Unicode18 `[0,6]`

### Requirement: 保护语义独立于展示

脚注内容/引用、目录与 Front matter 的保护范围以及 HTML 源语义 MUST 独立保留；有限 HTML MUST 保留可见文字及不可见源码，不执行网页能力。关联 MD-07～11、E2/E4、S-12。

#### Scenario: 普通段落包含脚注引用

- **WHEN** 普通正文与只读脚注引用交错
- **THEN** 分别输出保护子区间，保留正文可编辑边界及导航来源，不以整段布尔锁替代保护

#### Scenario: 有限 HTML 与未知语法

- **WHEN** 输入支持标签、无 href 链接、注释、多字符实体、过滤标签和未知语法
- **THEN** 输出限定语义及来源；注释仅展示隐藏，HTML 格式命令边界可检；过滤标签字面处理，无脚本/iframe/网络执行

#### Scenario: 不完整与敌意输入

- **WHEN** 输入深嵌套、重复未闭合标签/引号、巨段/巨表或超过扫描/节点/改写预算
- **THEN** 检查预算并终止，返回类型化诊断和可靠区域原文或整体源码回退，不吞尾、不截断、不发布不完整可编辑映射

### Requirement: 导航索引为纯数据且绑定源快照

`Parsed` MUST 提供只读导航索引，条目源码与目标均为绑定同一快照的受检范围，MUST NOT 暴露 href、可写字段或 UI 状态。关联 MD-02/MD-04/MD-11、E2、S-5。

#### Scenario: 标题、目录与脚注导航

- **WHEN** 输入含顶层标题、`[toc]`、脚注引用与顶层脚注定义
- **THEN** 标题条目记录 `Some(1..=6)` 级别及标题块范围；目录条目的 `source` 是 `[toc]` 段落、`targets` 是全部顶层标题块范围并按源码顺序；引用与定义条目按事件规范化标签字节精确相等互相指向，目标按源码顺序，无匹配时为空；其余条目级别为 `None`

#### Scenario: 导航边界与失败回退

- **WHEN** 标题/定义嵌套在引用或列表中、脚注标签仅大小写不同、标签重复、GFM 无定义字面量、导航预算超限或解析因预算回退原文
- **THEN** M0 只索引顶层标题/定义，嵌套引用仍按事件索引而嵌套 `[toc]` 不产生条目；无定义字面量不产生条目，大小写差异的已知解析器不一致产生空目标；重复标签保留源码顺序的全部目标；全部范围绑定同一快照、字段私有且无公开构造器；导航槽位在目标分配前预检，超过 `max_nodes` 或溢出时整源回退且索引为空，不截断、不伪造未索引目标

#### Scenario: 导航条目复用

- **WHEN** 两次解析对含标题的块承认复用
- **THEN** 生产复用判定仍只比较块种类与文本；测试 oracle 用 `ReusedBlock::translate` 重定位旧 `Heading` 条目的 `source` 两端后与新索引的 kind/level/source/空 targets 一致，复用块内无 Toc/脚注/嵌套 Heading 条目，旧绝对范围直接使用失败；顶层脚注定义、任意脚注引用和顶层 Toc 段落按全局依赖拒绝复用，嵌套脚注定义经 `ReferenceDefinition` 拒绝，嵌套 `[toc]` 可随可复用容器复用但不产生导航条目；不把拒绝或标题锚点写成链接目标复用通过
