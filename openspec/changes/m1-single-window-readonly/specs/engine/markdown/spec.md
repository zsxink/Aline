# Spec Delta

## ADDED Requirements

### Requirement: 只读结构展示与局部命中保留统一来源

解析结果 MUST 向只读消费者提供基础 Markdown 嵌套结构、语义样式、代码逻辑行及表格行列/对齐所需的不可变数据，并保留所属源码快照、保护语义和绘制来源。局部布局片段到全文绘制/源码的适配 MUST 通过受检映射边界，MUST NOT 要求 UI 重扫 Markdown、自建坐标换算或从结构重建源码。已有块/Gap、导航与映射契约继续适用。关联 MD-01～11、引擎 §4/6/7/11、R-4/12、S-3/5。

#### Scenario: 嵌套结构和局部消费
- **WHEN** 无窗口消费者读取标题/强调、嵌套列表/引用、任务项、Alerts、代码、表格转义管道与 HTML 样式，并只请求一个可见片段
- **THEN** 获得足以区分层级/样式/行列的语义数据及受检来源范围，片段内命中可经同一映射关系回全文源码；顶层块仍排除尾分隔，块/Gap 完整覆盖，原文 bytes 不变

#### Scenario: 多源隐藏合成和导航副本
- **WHEN** 片段跨实体、隐藏标记/注释、合成换行或目录/脚注的展示副本
- **THEN** 保留精确性、来源范围及规范锚点；导航文字来源与目标独立，不能以片段起点加裸整数充当跨坐标映射或伪造单调/双射

#### Scenario: 非法局部范围和旧身份
- **WHEN** 请求半字符/越界片段、错误快照/投影身份，或用旧片段命中新投影
- **THEN** 返回类型化拒绝，不 clamp、不访问错误文字、不发布部分映射；拒绝不改变源快照或已发布结构

#### Scenario: 结构预算取消与回退
- **WHEN** 深嵌套/巨表/巨段超过结构或映射预算，或解析收到取消
- **THEN** 取消返回取消且无部分树；超限沿现有错误/可靠原文回退协议并带诊断，范围完整、导航不伪造；引擎不创建线程/全局状态/GPUI 数据

## MODIFIED Requirements

### Requirement: 导航索引为纯数据且绑定源快照

`Parsed` MUST 提供只读导航索引，条目源码与目标均为绑定同一快照的受检范围，MUST NOT 暴露 href、可写字段或 UI 状态。关联 MD-02/MD-04/MD-11、E2、S-5。M1 对解析器已识别的脚注引用/定义 MUST 使用与同一解析链一致的标签等价关系建立导航，不因标签大小写差异丢失已有语义目标；顶层范围和其余来源约束保持。

#### Scenario: 标题、目录与脚注导航
- **WHEN** 输入含顶层标题、`[toc]`、脚注引用与顶层脚注定义
- **THEN** 标题条目记录 `Some(1..=6)` 级别及标题块范围；目录条目的 `source` 是 `[toc]` 段落、`targets` 是全部顶层标题块范围并按源码顺序；引用与定义按同一解析链的标签等价关系互相指向，目标按源码顺序，无有效匹配时为空；其余条目级别为 `None`

#### Scenario: 导航边界与失败回退
- **WHEN** 标题/定义嵌套在引用或列表中、脚注标签重复、GFM 无定义字面量、导航预算超限或解析因预算回退原文
- **THEN** 继续只索引顶层标题/定义，嵌套引用仍按事件索引而嵌套 `[toc]` 不产生条目；无定义字面量不产生条目；重复标签的有效目标保留源码顺序；全部范围绑定同一快照、字段私有且无公开构造器；导航槽位在目标分配前预检，超过 `max_nodes` 或溢出时整源回退且索引为空，不截断、不伪造未索引目标

#### Scenario: 导航条目复用
- **WHEN** 两次解析对含标题的块承认复用
- **THEN** 生产复用判定仍只比较块种类与文本；测试 oracle 用 `ReusedBlock::translate` 重定位旧 `Heading` 条目的 `source` 两端后与新索引的 kind/level/source/空 targets 一致，复用块内无 Toc/脚注/嵌套 Heading 条目，旧绝对范围直接使用失败；顶层脚注定义、任意脚注引用和顶层 Toc 段落按全局依赖拒绝复用，嵌套脚注定义经 `ReferenceDefinition` 拒绝，嵌套 `[toc]` 可随可复用容器复用但不产生导航条目；不把拒绝或标题锚点写成链接目标复用通过

#### Scenario: 已识别脚注大小写与回跳
- **WHEN** 同一解析器把 `[^Note]` 与 `[^note]:` 等标签等价的引用/顶层定义配对
- **THEN** 索引提供受检的引用到定义和定义到引用目标，标签显示不改源码；不再输出由字节精确比较造成的假空目标。匹配/重复/预算金样先冻结，不能只改现状测试为通过或新增未准入匹配库
