# Spec Delta

## ADDED Requirements

### Requirement: 只读会话不依赖打开编辑块

文档核心 MUST 支持以解码源码建立不开编辑块、无草稿/组合和空历史的只读会话，允许在文档层读取当前快照、受检导航和采纳当前解析结果。只读导航及两视图切换 MUST 不生成补丁、不推进文本 revision、不改变历史；M1 写入尝试 MUST 在变更前拒绝。编辑会话的既有初始化、分组、组合与发布协议 MUST 保持兼容，不把关闭编辑块等同于关闭只读文档。关联架构 §5/13、引擎 §3/7/8、R-3/5/6。

#### Scenario: 无编辑块的有效文档
- **WHEN** 创建只读会话并读取快照、导航至合法源码锚点、切换视图及采纳匹配解析
- **THEN** 全部可在没有打开块的情况下完成；唯一文档源码/选区和模式归核心，来源/版本明确，文本/revision/空历史不变，不能为绕过前置检查临时开块

#### Scenario: 只读拒绝和非法导航
- **WHEN** 只读会话收到开块、输入、组合、命令/重载/历史变更意图，或导航范围非法/属于旧快照
- **THEN** 明确拒绝且调用前文本、选区、模式、草稿、历史及有效请求状态不变，不给消费者可写 Buffer 句柄

#### Scenario: 文档关闭与旧结果
- **WHEN** 只读文档关闭/替换，或解析配置/请求已更新后结果才到达
- **THEN** 复验文档存活与文档/工作版本/快照来源/配置/请求等实际依赖键；过期拒绝、不复活；仅“无打开块”本身不使存活只读文档的匹配结果失效

#### Scenario: 编辑协议保持兼容
- **WHEN** 既有编辑会话运行开块、900ms 输入组、组合确认/取消和派生结果测试
- **THEN** 保持既有行为，不因新增只读分支放宽编辑会话的关闭目标检查或改变 M0 历史粒度
