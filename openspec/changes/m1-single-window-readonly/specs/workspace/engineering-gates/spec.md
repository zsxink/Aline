# Spec Delta

## ADDED Requirements

### Requirement: M1 只读出口按分项和平台交接

M1 交付 MUST 对架构 §13 的单窗/打开/点击、双虚拟视图、HTML/灰区/大纲/代码行号、1 MiB 滚动，以及 V-03/V-07 基础夹具、V-04 字体、V-05 首轮 Release 基准、V-09 主窗、V-01 macOS 冒烟逐项记录真实结果。MUST 区分 M0 用户验收豁免、无头证据与原生实验，保留 M0 未补证项；AC-01/09 MUST 仅声明 M1 相关阅读/字节/展示分项，MUST NOT 声称完整 AC-16 或其他整项 AC/V 已通过。关联 CODE_STANDARDS §6、开发流程 §5、R-11/17、S-12/14/19。

#### Scenario: 完成 M1 macOS 分项
- **WHEN** 在实际 macOS 设备执行原生冒烟、中文界面键盘、字体实验和长文 Release 测量
- **THEN** 记录设备/系统/架构/工具与 GPUI 身份、输入夹具、操作和计时边界、冷热缓存、样本次数/P50/P95、最长主线程停顿与内存；逐项列成功/失败/未测及证据位置，不把只读阶段补成保存重开/IME/完整插件实验

#### Scenario: 无设备失败取消或测量不完整
- **WHEN** Windows 10/Intel Mac/Linux 未测，原生后端/字体/1 MiB 操作失败，实验取消或只有无头测试数据
- **THEN** 明确保留对应缺口/失败，不用 all-targets、依赖解析或截图代替实际平台/性能结果；失败的 M1 必需出口不标完成，不降低 PRD 目标或静默移除兼容目标

#### Scenario: 原始输出与复现资产归属
- **WHEN** 保存本轮命令/截图/基准数据、夹具/独立预期或准备交接
- **THEN** 原始输出和逐轮 Agent 报告只在不追踪的 logs/validation 下，路径经统一归一化；正式测试/脚本/独立夹具进入对应源码测试目录，结果摘要回填既有验证计划/架构，当前交接至多一份不追踪 tmp 文档，不建立入库报告树

#### Scenario: 新增或修改自动守卫
- **WHEN** 为 M1 调整依赖/feature/安全/catalog/证据检查或增加新的自动拒绝条件
- **THEN** 在既有门禁入口提供合规正例和最小违规反例，证明拒绝原因并说明盲区；继续检查八成员有效 lint 继承与完整依赖闭包，不用刷新受审指纹或文档声明代替实际审计

### Requirement: M1 骨架候选数值不得记为冻结值

M1 状态栏统计口径（字符数与行数的定义）SHALL 作为实验候选，证据与文档 MUST 标注其未冻结状态与待 V-07 收口；MUST NOT 把该口径写成冻结值、发布门槛、验收通过依据或已验证结论。骨架证据 MUST 按区域分项记录实际观察结果与未测项，并统一标注区域高度、内容列宽、留白、字号行高等布局数值「取自原型参照、尚未经 V-09 冻结」——这些布局数值的候选性质由 `ui/main-window-layout` 的 W5 规定，本要求只约束其证据/文档的标注方式与收口边界，不重复定义布局数值本身。关联 UI §3.3/§4.1、CODE_STANDARDS §6、R-11/17、S-19。

#### Scenario: 记录骨架实测结果
- **WHEN** 在真实 macOS 窗口上采集骨架、工具栏、状态栏与内容列的实测结果
- **THEN** 逐项记录设备/系统/架构/工具与 GPUI 身份、窗口尺寸、观察到的区域构成与数值及其条件，并标注这些数值取自原型参照且尚未经 V-09 冻结；不以"与原型一致"代替实际观察，也不声称整项 V-09 或 AC-15/AC-16 通过

#### Scenario: 把原型数值当作既定门槛
- **WHEN** 实现或评审中出现"必须等于原型像素""原型数值已冻结""骨架已通过 V-09"这类表述
- **THEN** 判定为记录口径错误并改回候选表述；原型只提供形状与取数起点，冻结与否由对应 V 项的实测裁决

#### Scenario: 候选口径与文档不一致
- **WHEN** 实现采用的统计口径、留白或列宽与现行文档记录的候选口径不一致
- **THEN** 先修正实现或更新文档中的候选说明并记录变更理由，不在无说明的情况下留下两套口径；实际取值与冻结状态在文档中唯一且可查

### Requirement: 界面语言验证只做中文

自 2026-11-03 用户裁决起，界面语言的人工/原生验证及验收取证 SHALL 只以中文界面执行；MUST NOT 将切换系统首选语言到英文、复验英文界面作为 M1 或后续阶段的必需步骤。zh-CN/en 双语 catalog、`Translator::embedded` 的键集合/占位符一致性校验及缺键/漂移反例自动检查 MUST 保留，MUST NOT 因验证范围收窄而删除或降级。该约束只涉及界面语言取证；文档正文、文件名等英文内容排版样本不受限。关联 APP-04、AGENTS 铁律 7、UI §14、V-09。

#### Scenario: 中文界面取证
- **WHEN** 执行原生启动、窗口状态、文案、键盘焦点或截图类界面验证
- **THEN** 只记录中文界面的观测与证据，英文文案由 catalog 键/占位符自动校验覆盖；不要求切换系统首选语言复验英文，也不因缺少英文截图判失败

#### Scenario: 双语自动校验不可省略
- **WHEN** 评审或门禁以"验证只做中文"为由准备删除、跳过或降级双语键/占位符检查
- **THEN** 拒绝该改动；任一 catalog 键缺失、键集合不一致或插值漂移仍须使自动检查失败并记录诊断
