# Spec Delta

## Purpose

为 M2 单文档可编辑界面定义真实平台文本和组合输入的消费行为，保持唯一源码、输入组与历史，并对 UTF-16、UTF-8 字节、字素及候选窗坐标建立可验证边界，避免模拟输入掩盖真实中文输入法、焦点和平台回调问题。

## ADDED Requirements

### Requirement: 原生输入保持唯一组合和共享历史

原生普通输入和组合输入 MUST 进入唯一打开块及统一输入协议，两种模式 MUST 共享源码与历史。普通相邻输入按 900ms 分组；IME 确认独立一步，取消恢复组合前内容/选区且不留空历史；过期回调 MUST 拒收并保留当前上下文。关联 TA-01、EDIT-04～06、AC-03/04。

#### Scenario: 候选替换确认和取消

- **WHEN** 真实输入法连续更新/替换候选，然后确认或取消
- **THEN** 候选只保留在一个组合槽；确认只产生独立一次历史，取消不写入候选，旧代次不能复活

#### Scenario: 只读或失效投影输入

- **WHEN** 输入指向只读能力、已关闭块、旧文档或旧投影
- **THEN** 明确拒绝，不改变当前文本、草稿、组合、选区或历史，不通过旧范围写入

### Requirement: 平台文本坐标受检转换

平台 UTF-16 端点、布局 UTF-8 字节索引与字素移动 MUST 在各自声明的投影内使用，经映射层受检转换；MUST NOT 手算块/行偏移或拆开代理对、组合字符和 ZWJ 字素。选区跨块时 MUST NOT 将组合拆入多个块；无法可靠表达的输入按已确认能力拒绝并保留上下文，不新增跨块组合语义。关联引擎 §7/10、R-4、RS-02。

#### Scenario: Unicode 和 CRLF 边界

- **WHEN** 文本含中文、emoji ZWJ、组合重音或 CRLF，平台提交 UTF-16 范围
- **THEN** 只对当前投影中受检对应的源码范围操作；半代理对、半 UTF-8 或过期身份明确拒绝且零副作用

### Requirement: marked 生命周期与焦点操作不丢输入

菜单借焦点、点击其他块、切模式和窗口失活 MUST 显式协调平台 marked 与组合状态。等待平台结果期间 MUST 保留原上下文，不抢焦点、不以 Blur/Escape 猜确认或取消、不用定时器伪造结束；完成后清理失效 marked 并恢复存活的输入上下文。关联 QMD-01.4、UI §6/13、R-8-04。

#### Scenario: 组合中借焦点和切块

- **WHEN** 中文组合活动时用户打开菜单、点击另一块或切模式
- **THEN** 依据平台自然结果协调操作，原候选和草稿不丢失；目标动作不抢先使用旧投影，完成后无残留 marked 或幽灵候选

### Requirement: 候选窗遵循实际布局坐标

候选窗位置 MUST 基于当前元素 frame、文本布局位置、滚动偏移和窗口坐标转换；折行、滚动、DPI 和多屏变化后 MUST 重算。组合揭示 MUST 复用统一定位机制，不以直接改列表偏移形成第二个滚动所有者。关联引擎 §10.1、UI §6、V-01/07。

#### Scenario: 长文边缘输入

- **WHEN** 虚拟列表边缘的组合文本发生折行、滚动或显示缩放变化
- **THEN** 候选窗跟随真实插入点且组合内容可见，不使用上次布局或未滚动坐标

### Requirement: 组合期发布保持可取消等待

组合未结束时显式保存/另存为请求 MUST 可取消地等待平台自然确认或取消后取当时当前快照；自动保存延后，恢复独立保护当前输入和资源。取消请求 MUST NOT 取消输入或改变历史。关联 ED-01、AC-05、W4。

#### Scenario: 等待中继续候选或取消请求

- **WHEN** 等待保存期间候选更新，或用户取消保存请求
- **THEN** 未结束前不发布候选；自然结束后取最新快照，取消请求只撤发布意图并保留当前组合和焦点
