# Design

## Context

动机见 proposal。DocCore 已维护普通输入、唯一组合槽、发布等待及身份；原生窗口仍只读，未接平台文本输入 handler。无头组合成功不代表系统候选窗和焦点成功。依据 PRD §5.3、引擎 §7/8/10/17、UI §6/13、架构 §5/13、R-4/8、CODE_STANDARDS §2～6；W5 研究步骤只作线索。

M1 出口、M2 可编辑块与输入投影是接线前置；W4 真实保存消费者是发布交错平台验收前置。当前允许准备锁定 API 证据、独立坐标/事件样本，不在 M1 提前开放输入。

## Goals / Non-Goals

**Goals:** 唯一 DocCore 组合所有者，版本化输入投影，真实平台 callback 明确结算；候选窗、marked 和焦点有可复核生命周期。

**Non-Goals:** 不增加新输入模型/历史，不实现跨块组合或 M3 命令全集，不改变 ED-01，不把离屏或合成输入列为真实 IME 通过。

## Decisions

### 1. 具体适配和状态边界

DocCore 唯一拥有草稿/组合/输入组，平台适配持当前投影身份及弱宿主目标，转发平台 UTF-16 查询/替换/marked 事件。渲染只消费派生组合视图，不拥有第二份可提交候选。M2 打开块和 Source 输入共用受检提交及历史。采用具体 adapter 与明确 enum 状态；锁定 GPUI trait 实现只在 UI，不能把平台 trait 引入引擎。新增模块按输入生命周期/坐标几何职责分离，不按行数机械拆分；没有真实消费者不扩大公开 API。

### 2. 三坐标和投影身份

平台端点使用 UTF-16 受检封装，glyph/layout 索引视为该布局中的 UTF-8 字节，普通移动删除以字素；都必须声明 document/working/projection/block/config 身份并经统一映射，不手算块首/行首。半代理对、半 UTF-8、旧投影和无法对应范围拒绝且保留原状态。跨块选区按既有可编辑投影能力向平台报告，不能虚构一个可跨块写入的 marked 范围；若锁定平台无法表达，先拒绝并保留，不擅自裁剪输入或新增产品语义。

### 3. 生命周期协调

普通输入和 IME 分别复用 DocCore 既定协议。候选更新推进草稿代次，确认独立一次历史，取消恢复前态且旧投影不复活。菜单暂借焦点保留上下文；实际失焦、切块、模式/窗口转换须先协调平台自然结果，再清理失效 marked 并执行目标操作。不能将研究中的“一律 unmark”理解为强制确认/取消；Blur/Escape/计时器不能决定组合结果。未得平台自然结果时保留上下文并等待或拒绝目标动作，反馈可取消的发布请求但不取消输入。

回调复验目标存活和完整输入身份；关闭作废采纳资格并释放 handler/订阅，晚到事件不重开目标。Undo/Redo/写入口也遵守组合门控，不在平台与 DocCore 各自提交一次。发布请求使用既有 wait handle；W4 负责写盘，W5 只提供自然结束后当前快照资格。

### 4. 候选窗几何与揭示

几何来自当前 prepaint 文本布局、元素 frame、滚动及窗口坐标；输入投影与布局必须对应同一身份。折行/滚动/缩放/字体代次变化失效旧几何，再计算候选插入点矩形。跨屏按平台窗口坐标契约，不把屏幕坐标直接传给 handler。组合揭示沿用统一 Reveal，避免直接修改虚拟列表偏移形成竞争所有者。具体锁定 GPUI callback 名称和坐标单位在接线 spike 中留 verbatim 源码锚点，不能按较新 GPUI API 猜测。

## Risks / Trade-offs

- 原生 IME 回调顺序与焦点行为未知 → macOS 中文输入法逐项观察/事件记录，记录身份和错误、不记录正文/候选敏感内容；模拟测试只证协议。
- 旧布局候选窗错位 → identity 检查与几何失效，虚拟列表边缘、折行、DPI、多屏实测；缺平台则保留未测。
- unmark 语义可能触发平台提交 → 先以锁定源码和真实事件取证，保持自然结束/原上下文契约；若能力确实不足，列具体最小冲突，不能用假确认绕过。
- 输入路径热计算 → 不在按键/render 全文解析或 I/O；复用局部输入投影，性能按 V-05 量测。

## Migration Plan

先加受检投影与无头事件金样，锁定平台能力 spike，再在 M1 出口后接 M2 输入；仅适用入口启用，所有写入口持续受 MD-11 保护。任何替代路径/旧 handler/无消费者 fake/导出应清理并查引用。回撤 handler 前先结算自然组合结果并保存当前上下文，不能通过销毁 UI 丢候选。W4 未接通时仅完成等待协议测试，真实保存交错保持未完成。
