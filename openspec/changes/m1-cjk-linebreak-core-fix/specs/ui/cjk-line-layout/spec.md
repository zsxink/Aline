# Spec Delta

## Purpose

规定中文只读文本自动折行后的开闭标点与字形边界行为，使读者在可视化和源码视图的窄列中保持可读性，并继续使用与绘制一致的命中几何。此要求不修改文档字符、显式换行、源码保真或编辑阶段范围，也不把字体观察升级为合成斜体能力。

## ADDED Requirements

### Requirement: 中文软折行选择合法字形边界

两种只读视图 SHALL 在保持原始文字与显式换行的前提下选择合法自动折行边界。具有可用合法断点的正文 SHALL 不因自动折行使闭标点脱离前文而处于行首，或使开标点脱离后文而处于行尾。断点 MUST 位于有效 UTF-8 及实际字形簇边界；组合字符、emoji ZWJ 与同一字形簇 MUST NOT 被切开。明确由原文开始或显式换行产生的标点行首不属于自动改写理由。

#### Scenario: 普通中文开闭标点与混排

- **WHEN** 中文夹具在 320/480/768 正文逻辑宽自动折行，且该行存在合法候选边界
- **THEN** 开闭标点与对应前后文保持合法软折行关系，英文单词、数字、普通空白与原来的显式换行语义保持，展示字符不增删

#### Scenario: 宽度变化与复杂字形

- **WHEN** 正文含中文、拉丁字母、组合字符、emoji ZWJ，随后改变宽度或字体身份
- **THEN** 重新计算真实字形几何和合法断点，不使用过期布局或在字形簇内部断开

### Requirement: 断行修复保持同一几何与受限输入的诚实结果

修复后的文字绘制、像素命中、源码定位与滚动恢复 SHALL 使用同一当前布局身份及统一映射；MUST NOT 用插入换行、零宽字符、替换空白或另造未校验行几何达成视觉效果。无合法可用断点、超宽字形或超过既有安全预算时 MUST 保留原文与可达入口并给出真实受限结果，MUST NOT 静默裁切、丢字、无限循环、panic，或硬断后声称符合中文排版。

#### Scenario: 折行边界两侧点击与两视图往返

- **WHEN** 在真实窗口点击新折行边界两侧的字形并进行源码与可视化往返
- **THEN** 命中经当前布局和映射到合法源码端点，磁盘原 bytes、内存源码、revision、草稿和历史不变

#### Scenario: 不存在合法断点或字形超过宽度

- **WHEN** 输入由连续标点或超宽字形组成，当前宽度和预算无法形成合法可绘制行
- **THEN** 有限时间内产生可检查的受限/失败结果并保留原文，不把错误断行、隐藏正文或未取得的平台能力记成正常通过

#### Scenario: 旧布局或文档已替换

- **WHEN** 宽度、字体或文档身份变化后收到旧点击或旧定位结果
- **THEN** 继续按既有身份协议拒绝或重算，不把旧字形位置应用到新投影
