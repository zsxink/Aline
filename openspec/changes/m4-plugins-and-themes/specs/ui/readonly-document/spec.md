# Spec Delta

## MODIFIED Requirements

### Requirement: Markdown 有限 HTML 与保护区展示

可视化 SHALL 呈现 MD-01～03 的基础块、行内样式、嵌套引用/列表/任务项、基础表格结构及五类 Alerts；SHALL 按 MD-07～09 呈现有限 HTML 样式/可见文字，不执行脚本、不加载 iframe/外部资源、不使用网页盒模型。脚注内容、目录与 Front matter SHALL 为可辨灰色只读区，脚注引用保留导航，已启用且成功生成的公式、Mermaid 和受支持的图片 SHALL 展示当前资产，未知语法、已关闭或不可用的预览 SHALL 保留原文或可识别引用回退；SHALL NOT 将基础语法全篇回退当完成。关联 AC-09 展示分项、UI §7、V-03/V-07。

#### Scenario: 基础语法与灰区
- **WHEN** 打开五组真实语法夹具，包含完整文首 Front matter、脚注、目录、列表/引用内表格与 Alerts
- **THEN** 层级、样式、表格行列/对齐和提示类型可辨；灰区与普通代码可区分，灰区不借用代码语言控件；正文内脚注引用独立表达保护，M1 所有区域均不开放写入；M4 开放代码块编辑后，灰区与受保护区域仍不开放写入

#### Scenario: 有限 HTML 与原文保留
- **WHEN** 内容包含支持样式标签、实体、注释、过滤标签、交叉嵌套、未知标签或未闭合围栏
- **THEN** 按引擎有限语义展示，注释仅展示隐藏且源码可达，过滤标签字面可见、无执行/网络副作用；未知/错误内容保留来源及安全原文，未闭合 Front matter 不吞整篇

#### Scenario: 降级或过期投影
- **WHEN** 预算/解析失败导致回退或替换文档后旧结构/样式结果返回
- **THEN** 明确显示当前诊断与只读原文入口，不显示成功渲染状态，不挂旧内容；解析器以 `BudgetExceeded` 或 `RawFallback` 诊断返回整源回退时，默认进入 Source 只读原文视图并显示本地化原因；公式/Mermaid 回退不表示其后端支持矩阵通过

### Requirement: 普通代码行号与键盘基线

围栏与缩进代码 SHALL 使用相同普通代码外观，行号从 1 开始、空行计数、软折行不重复，未知语言按普通代码处理。所有产品文案 SHALL 经 zh-CN/en catalog，首轮按系统首选语言选择界面语言（这是启动读取的产品行为，不等于要求切换语言复验英文；人工/原生界面取证只做中文、双语 catalog 自动校验保留，见 `workspace/engineering-gates` 的界面语言验证要求）；已开放的打开/切视图/大纲导航/关闭/反馈与滚动 SHALL 可键盘访问且焦点可见。M1 SHALL NOT 显示可执行的语言修改、编辑、保存或插件成功状态；M4 SHALL 开放代码块语言与复制控件（见 `ui/editable-document`），灰区与受保护区域仍不开放写入。关联 PRD §6.2/6.3、APP-04、AC-15/20 分项、V-04/V-09。

#### Scenario: 代码长行与空行
- **WHEN** 围栏/缩进代码含空行、未知语言、中文/emoji、无末尾换行和长行
- **THEN** 行号与代码基线对齐，仅属于视图、不进入代码文本；横向和主纵向访问均可操作，字体回退不改源码

#### Scenario: 中文界面与焦点返回
- **WHEN** 以中文界面运行，使用键盘打开并取消选择、切视图、激活大纲和访问失败反馈
- **THEN** 控件名称与错误完整可读、无缺 key/插值漂移，取消返回先前可用焦点，无仅鼠标可达的核心流程；英文文案由 catalog 键/占位符一致性与缺键反例自动校验覆盖，完整设置与即时切语言验收留后续阶段

#### Scenario: 字体或平台动作失败
- **WHEN** 字体注册/所选字族不可用、中文缺字回退异常，或原生文件选择失败
- **THEN** 明确反馈实际失败/回退状态，保留文档与位置，不把未激活字体或失败动作显示为成功，不以 macOS 结果推断其他平台
