# Spec Delta

## Purpose

规定用户从当前文档导出 PDF、DOCX 与 HTML 的真实输出、版本边界及取消失败语义，覆盖内容样式、内嵌资源和其他插件开关的组合。

## ADDED Requirements

### Requirement: 导出当前版本的真实文档

导出 SHALL 在动作确认时按 EXPORT-01～06 和 ED-01 冻结可发布快照及有效配置。PDF 使用独立页样式，DOCX 使用文档样式及适用代码选项，HTML 遵循离线资源约定。格式保真及可编辑边界 SHALL 可验证。关联 AC-14、V-02。

#### Scenario: 三格式可打开
- **WHEN** 导出包含标题、列表、表格、代码、图片、公式、图表与安全 HTML 的文档
- **THEN** PDF、DOCX、HTML 可在对应阅读器打开；按已确认的格式和插件矩阵体现结构、资源及回退

#### Scenario: 输入法组合与版本隔离
- **WHEN** 组合期间请求导出且平台随后自然结束组合
- **THEN** 取结束后的当前快照，候选和后续变更均不混入产物，导出不改编辑历史与保存点

### Requirement: 导出选项覆盖已确认格式矩阵

导出 SHALL 按 EXPORT-02～04 提供格式专属选项：PDF 提供 A4、A3、Letter、Legal 纸型、纵向/横向与四边独立页边距，默认 A4 纵向；DOCX 提供标题/正文的随文档、紧凑、标准样式与代码的随主题、浅色、深色、纯文本样式；HTML 默认包含样式并可关闭，图片可复制到输出资源目录或保留引用。选项默认值、分页与跨页效果、可编辑边界 SHALL 以 V-02 实测冻结为准，不得以旧页边距值或纯文本 Word 产物替代。关联 EXPORT-02～04、UI §11.3、AC-14、V-02。

#### Scenario: 纸型、方向与页边距
- **WHEN** 用户选择非默认纸型与方向并分别设置四边页边距后导出 PDF
- **THEN** 产物页面尺寸、方向与四边边距与所选一致，默认仍为 A4 纵向；分页及代码/表格跨页效果按 V-02 样本核对

#### Scenario: DOCX 样式组合
- **WHEN** 用户选择标题/正文样式与代码样式后导出 Word
- **THEN** 标题层级、正文与代码块按所选样式呈现且正文可编辑；公式/图表静态图像的可编辑性边界有说明

#### Scenario: HTML 样式与资源策略
- **WHEN** 用户关闭 HTML 样式，或选择把图片复制到输出资源目录
- **THEN** 产物按所选策略离线可读；样式关闭、资源复制失败或缺失有明确反馈，不发布半成功产物

### Requirement: 导出失败保留原输出

系统 SHALL 在输出发布前处理目标冲突、取消、预算与任务有效性。取消等待、关闭导出、拒绝覆盖或失败 SHALL 保留原目标及编辑状态。

#### Scenario: 写出途中失败
- **WHEN** 已确认覆盖且后端生成失败或任务已取消
- **THEN** 原目标保持不变，不留下部分成功的产物，也不显示成功提示
