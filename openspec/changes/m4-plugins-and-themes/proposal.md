# Proposal

## Why

M3 已于 2026-11-24 在 macOS arm64、简体中文、2× 范围完成阶段核对并归档。M4 要把现有编辑器的插件边界、图片迁移和窗口基线推进到可实际使用、可取证的插件、主题、设置与导出能力。

## What Changes

- 交付六个默认开启的内置插件、公共注册与启停契约，以及测试提供者。保留基础表格、普通代码、源码与内嵌图片的独立核心行为。依据 PRD §5.8、插件规范 §4～10、PL-01～03。
- 交付生产图片插入、引用迁移及只读图片预览。PDF、DOCX、HTML 交付真实可打开的产物。依据 IMAGE-01～08、PREVIEW-01～04、EXPORT-01～06 与 ED-01。
- 交付 GitHub、Notion、Vue、飞书四套主题及三种模式、完整语义样式、主题包导入/刷新、原生字体激活和主窗口内设置。依据 THEME-01～09、APP-01～06、UI §9～14、TH-01～10、W2/W6 的 M4 落点。
- V-02～V-04 仍有待冻结的格式细则、后端、支持范围及实测预算。先提交候选、样本和实际结果，再开展依赖对应裁决的生产实现。V-06 资源预算与 V-07 统计口径按各自验证计划处理。
- 补齐 M4 入口复核发现的出口级缺项：代码块语言与复制控件、导出选项矩阵、Mermaid 自定义主题导入与管理、链接/图片编辑弹窗与图片右键操作、状态栏外观模式与快速主题入口、主窗口布局规格的 M4 阶段推进，以及 M3 已登记的列表呈现缺口。
- 外部插件加载及市场属于 V1 范围外。多窗、完整标签与文件树、路径联动及工作区恢复按 M5 实施。当前阶段取证按决定 §24/45 和架构 §13 执行，V1 出口仍需三平台验收。

## Capabilities

### New Capabilities

- `ui/built-in-plugins`：六内置插件、公共启停、渲染与表格增强。
- `ui/document-export`：冻结快照、真实三格式输出与事务。
- `ui/image-resources`：正文图片、生产插入迁移和只读预览。
- `ui/appearance-and-settings`：主题、包、字体、全局设置与会话级降级反馈。

### Modified Capabilities

- `ui/readonly-document`：完整资产接入后，明确受支持内容的展示与统一回退。
- `ui/main-window-layout`：把设置页、导出/主题入口与状态栏外观模式、快速主题入口推进到 M4，标签栏、侧栏与文件树仍归 M5。
- `ui/editable-document`：新增代码块语言与复制控件，作为核心编辑能力随 M4 交付。

## Impact

涉及 `aline-plugin` 注册、能力与计算，`aline-app-core` 纯设置与主题模型及 catalog，`aline-ui` 文档资源、字体、调度和事务，`app` 原生入口。现有引擎保持源码真源和单向依赖。适用 CODE_STANDARDS §2～6、R-1-07/R-6-06/R-11-01/R-15-08～12、S-3-01/04、S-7-01/02、S-11-04。

出口按架构 §13 核对 AC-10～14/19/20、APP 相关 AC-15 分项和 V-08 资源链路。证据包括原生启停及回退、三格式独立应用打开、合法及恶意主题包、运行时字体切换和资源迁移故障注入。后端能力和依赖准入是主要风险，须按现行架构 §3.2 与引擎 §18.2 单独核实。
