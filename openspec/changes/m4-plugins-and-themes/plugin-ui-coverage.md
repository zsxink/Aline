# 插件 UI 门控与采纳覆盖记录（任务 2.3）

本记录对应任务 2.3，冻结 `aline-ui` 侧插件门控与任务采纳的当前边界。实现位于
`crates/aline-ui/src/plugins.rs`，用例位于 `crates/aline-ui/tests/plugin_gate.rs`。
设置服务、具体插件视图与真实入口尚未实现，本记录只声明模型层与采纳层已覆盖的
部分，不把后续任务的入口写成已核对。

## 六入口与设置一致性

`BUILT_IN_CAPABILITIES` 与 `BUILT_IN_SETTINGS` 固定六组双向映射；用例证明双向、
穷尽且互不重复，`EffectivePlugins` 的六个布尔值逐项转换为启用集合。入口本身按
所属任务交付，交付时必须复用同一映射与 `PluginGate::check_capability`。

| 插件 | 能力 | 设置字段 | 当前入口状态 | 入口所属任务 |
|---|---|---|---|---|
| Mermaid | `mermaid` | `MermaidEnabled` | 未实现 | 预览/渲染 4.2；独立图像命令 4.3 |
| 表格增强 | `table` | `TableEnabled` | 核心表格菜单存在，未接开关 | 4.1 |
| 导出 | `export` | `ExportEnabled` | 未实现 | 4.4 |

## 验证边界

- 门控只比较 `DocumentId` 与 `WorkingVersion`；完整 `InputIdentity`（快照、解析配置、
  派生请求）未强加给所有插件任务，按 §9.2 各行依赖在所属任务增量校验。
- 主题/资源代次是不透明单调令牌，不代表主题包或资源身份已实现；真实服务接线时
  每次来源变化必须推进对应令牌。
- 本任务不创建菜单、工具栏、设置页或任何插件视图，也不证明原生交互、主题视觉或
  资源迁移；这些分别由 3.x、4.x、5.x 及其 V 项取证。

## M5 标签/文件树回归登记（任务 3.3）

M4 的图片预览按 spec delta 以主窗口内的独立视口承载；与 Markdown 共用标签栏、
文件树和路径联动归 M5。以下用例在 M5 接入标签/文件树时必须复跑并取证：

| 回归项 | 验收点 |
|---|---|
| 图片作为 tab | 与 Markdown 共用标签栏，标题/路径一致，同一路径不重复开 tab |
| 路径复用 | 同路径再次打开复用已加载图与视口（百分比、平移、模式） |
| 多 tab 并存 | 切换 tab 保留各自视口；关闭一个图片 tab 不影响其它 tab 与正文图片 |
| 文件树选中 | 文件树打开图片与入口打开同一路径等价，选中态跟随当前 tab |
| 关闭与恢复 | 关闭 tab 不复活；常规重启不恢复图片 tab（PL-03） |
| 插件关闭 | 保留仍打开 tab 的路径/模式/视口，再启用按 PL-03 恢复；新预览请求被拦截 |
