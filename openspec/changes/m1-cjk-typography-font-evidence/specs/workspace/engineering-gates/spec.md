# Spec Delta

## ADDED Requirements

### Requirement: 中文排版测量分项证据

W2 测量 MUST 使用独立夹具，在正文实际宽度 320/480/768 px 下分别核对 Visual 与 Source 的全角标点避头尾、混排、字形/行高、合成斜体、CJK 标点回退与字体平滑。证据 MUST 记录真实平台、锁定构建身份、夹具哈希、实际宽度/缩放、截图及观察；未测、能力失败与历史字体结果 MUST 分开报告。MUST NOT 把源码静态检查、合成记录或参考数值写成真实渲染通过。

#### Scenario: 六组合观测齐全

- **WHEN** 六个宽度/模式组合均有真实截图、测量与观察且身份一致
- **THEN** 只报告该平台该构建的测量结果，另行记录是否需要上游或产品裁决，不推断三平台或完整 V-04 通过

#### Scenario: 证据缺失或能力失败

- **WHEN** 缺任一组合/真实截图/运行身份，或实际标点换行、回退、字形异常
- **THEN** 完整性检查失败或明确记录能力失败；不得以模板、旧字体截图或未获批准的 vendor 绕过
