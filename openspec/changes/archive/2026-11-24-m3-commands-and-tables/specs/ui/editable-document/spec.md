## ADDED Requirements

### Requirement: 格式与表格通过原生编辑入口操作

编辑器 SHALL 按 UI 规范提供格式菜单、适用快捷键、列表键盘操作、任务框与核心表格操作，基础表格独立于增强插件。

#### Scenario: 表格导航与右键目标

- **WHEN** 在已有单元格间导航，随后在另一单元格打开右键菜单
- **THEN** 导航只移动选区，源码和历史保持原样；右键操作解析到被点击的行列，复制优先输出原 Markdown；末格追加行作为独立结构命令

#### Scenario: 组合输入中触发命令

- **WHEN** 活跃 IME 组合期间触发格式或结构命令
- **THEN** 编辑入口禁用或反馈拒绝，保留当前组合、焦点、选区、草稿与历史

### Requirement: HTML 原文编辑遵循展示和保护边界

编辑器 SHALL 为 HTML 块提供原文编辑并维持限定 HTML 展示规则。可视化命令、跨块修改和替换继续遵守 MD-10 与 MD-11。

#### Scenario: 点击 HTML 块并修改原文

- **WHEN** 点击 HTML 块并直接修改带注释或实体的原文
- **THEN** 原文输入按现有事务提交并可撤销，范围外字节及未编辑的注释原样保留，展示按既有规则更新

#### Scenario: 跨块修改触及灰区

- **WHEN** 可视化删除、粘贴或替换触及脚注、目录或 Front matter 的受保护区间
- **THEN** 拒绝可视化写入并提供源码定位，文本和历史保持原样

### Requirement: 全文格式化经用户确认后原子应用

编辑器 SHALL 仅在“编辑 > 格式化 Markdown”开启差异确认，取消零修改，确认一次应用并一步撤销。

#### Scenario: 预览后取消或确认

- **WHEN** 用户从编辑菜单生成有效差异
- **THEN** 预览本身保持文档和历史；取消无修改，有效确认产生独立撤销步，撤销恢复源码与选区

#### Scenario: 预览过期或发生常规编辑事件

- **WHEN** 预览期间文档变化或切换目标文档，或者发生打开、保存、自动保存、模式切换或粘贴
- **THEN** 过期确认拒绝并提示重新生成；常规事件不触发格式化

## MODIFIED Requirements

### Requirement: 源码查找替换与过期结果保护

系统 SHALL 按源码查找当前文档，两种视图共享命中结果，支持大小写开关、当前项替换和一次操作内全部替换。替换计划 SHALL 绑定当前文档和工作版本；文档变化时 MUST 作废旧结果并在当前快照上重新查找。可视化查找命中不可见源码时 SHALL 定位到对应源码位置。可视化替换范围触及 MD-11 时，系统 MUST 拒绝整次操作并提供独立的源码定位动作。经用户进入源码模式后，新的替换意图 SHALL 基于当前版本重新计划完整操作；不得部分替换或绕过 MD-11。关联 PRD FIND-01～03、AC-08 与架构 §5.2。

#### Scenario: 查找并逐项定位
- **WHEN** 用户搜索含 Markdown 标记、HTML 注释或链接地址的源码文本并逐项跳转
- **THEN** 结果按源码匹配、显示命中数量和当前项，可视化不可见命中时进入对应源码位置；两模式结果保持一致

#### Scenario: 当前替换或全部替换
- **WHEN** 用户替换当前匹配项或执行全部替换
- **THEN** 当前版本上匹配的范围被受检补丁替换；全部替换作为单一用户操作且可一步撤销，含跨展示块匹配

#### Scenario: 文档变化、空查询或保护区
- **WHEN** 搜索后文档已变化、查询为空、无匹配、文档不可编辑，或可视化替换命中不可见源码/只读语法展示区
- **THEN** 不使用过期选区写入；显示明确空状态或拒绝；触及 MD-11 时保留当前选区、草稿和历史，并提供独立定位动作。用户进入源码模式后可按当前结果重新执行替换
