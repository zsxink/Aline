# Design

## Context

`aline-edit` 已提供 `plan_change` / `validate_change`，现有最小行内路径仅接受非空可视化选区。DocCore 已有受检提交、输入组和查找替换事务；markdown 提供展示投影、保护范围和有限 HTML。M3 扩展这些边界，沿用 PRD、引擎设计、UI 规范 §4.1 和 V-07。

## Goals / Non-Goals

**Goals:** 源码保真、命令复读、独立历史步、中文原生交互与本机 macOS 取证。

**Non-Goals:** M4 表格悬停增强、插件与主题，M5 应用壳，跨平台取证和完整 V1 发布验收。

## Decisions

1. `aline-markdown` 提供绑定快照的语法范围与投影。结构命令以受检源码范围读取原片段，用小补丁或单个结构范围替换表达重排。表格移动保留单元格、分隔行和对齐的关联，代码与转义按解析边界处理。视觉列索引仅用于定位，展示树不承担保存格式。
2. `aline-edit` 按行内/段落列表、表格、格式化的规则差异组织具体规划函数，共享现有版本绑定、预算、保护与复读校验。语义复读核对操作目标及邻接结构；未知结构、不可证安全的范围、超预算和过期上下文走枚举拒绝。公共边界只添加生产调用所需的命令和计划数据，维持五引擎无 GPUI、现有依赖方向与文件格式。
3. DocCore 持有源码、输入组、选区和历史的写入权。复用现有候选封口及受检提交路径，文本命令成功时独立记步，失败或无变化时保持原草稿和历史。普通导航与复制无写入；活跃 IME 无命令提交。原生窗口持有暂态右键目标和格式化预览，提交时校验文档、快照、投影、目标范围及适用选区，防止旧目标回写。
4. 格式化预览持有绑定当前文档身份及逻辑源码的差异。涉及草稿时使用只读逻辑快照，确认时重验并由 DocCore 原子应用；取消、过期和失败释放预览或提示重建。全文候选复读有成本，复用注入预算并以大输入和超限金样核查。
5. 窗口菜单、快捷键与右键通过共用命令定义核对启用、拒绝及焦点行为；双语 catalog 提供文案。HTML 原文编辑复用单槽输入与投影映射，格式命令保护和原文输入许可由不同语义入口检查。用真实菜单/按键/点击验证接线，用无头金样验证规则。

6. 普通 Tab/Shift-Tab 使用已采纳表格的源范围，通过 DocCore 映射到单区间草稿和目标格。菜单启用复用相同绑定。普通正文 Enter 先由阅读快照和打开块判断列表候选。引用与列表内表格复制逐行保留原 Markdown 和行尾，统一去除容器前缀。
7. 触及 MD-11 的拒绝保留选区、草稿及历史。窗口持有绑定当前输入身份的保护范围，用户显式触发才切源码重绑选区。格式化确认先查文档身份，再请求可写核心。

## Risks / Trade-offs

V-07 表头、整理、跨结构及格式化风格需在任务 1 冻结独立预期。遇到同级规范冲突，记录待确认并暂停依赖该结论的实现。复读增加结构命令成本，使用有界规划与可复跑证据保留安全拒绝。按 CODE_STANDARDS §2～6 独立复核 DocCore 历史、公开接口和保护边界。平台证据限本机 macOS arm64 与实际采样配置。


## Engineering Review

独立审查及复核覆盖结构命令、保护区、单一历史所有者、受检坐标和拒绝路径。按 CODE_STANDARDS §2～6、工程治理规格与架构 K／Rust C 核对，未引入 crate、依赖、可变公共访问器或第二写入口。原生验证修复了窗口焦点绑定抢占列表和表格 Tab 的问题，菜单绑定过期时归还焦点。

表格引擎集中保留源行、候选约束与复读闭环。原生表格模块同处管理目标绑定和菜单生命周期，回归与入口就近测试。按职责复核保留当前边界，后续扩展时可独立演进表格读模型和菜单视图。
