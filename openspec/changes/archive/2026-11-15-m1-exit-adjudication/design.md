# Design

## Context

M1 实现任务已归档（`openspec/changes/archive/2026-11-13-m1-single-window-readonly/`），但阶段出口没有单独的裁决记录。`docs/v1-architecture.md` §13 明确 M1 出口为「AC-01、AC-09 相关阅读/字节用例，1 MiB 可滚动的实际证据；macOS 首轮冒烟、Win10/Intel 目标未消失；读展示可检查，不伪称完整 AC-16 已过」；`docs/development-process.md` §1 规定 M2 的交接要求是「M1 通过」，且「阶段完成需回填架构阶段状态和验证计划证据」。本 change 以该行作为唯一判据，避免用「归档」「任务勾选」或任一 V 项整项状态替代出口核对。

## Decisions

### 1. 判据与范围

只按架构 §13 M1 出口行判定，不把下列内容当作 M1 出口：V-01/V-04/V-07/V-09 的整项通过、AC-15/16 整项、跨平台运行、真实 IME、M0 豁免缺口关闭、性能门槛冻结、视觉数值冻结。证据平台限定 macOS arm64、scale 2、界面中文（决定 §24）；Windows 10、Intel Mac、Linux 保持「目标未消失、证据未取得」。

### 3. 各 V 项裁决

- **V-01**：M1 判据只要求 macOS 冒烟与目标保留，二者满足；整项仍「未整项通过」，归 M5/M6 的跨平台、安装/分发与系统集成取证。
- **V-04**：M1 字体实验、中文回退、加载失败反馈、真实激活与锚点/命中已按分项记录；中文避头尾、CJK face 身份、平滑三项已按决定 §35/§41/§42 记为接受已知限制；整项归 M4/M6，运行中字体重排归 M4。
- **V-07**：M1 只读语法/映射/导航/像素命中与五样本七步已完成；编辑、IME、跨块、格式化、结构命令归 M2/M3；整项仍是 M3 前置（V-07 金样先于实现冻结）。代码块真实横向滚动交互未取得真实证据，列为 M2 入口待办，不构成 M1 出口阻塞。
- **V-09**：M1 主窗十四项矩阵、骨架/工具栏/状态栏/列宽/中文界面已完成；完整设置/菜单/主题矩阵与三平台归 M4～M6；骨架候选数值（880/56/768、40/100、900/600、12 px、16 px/1.75、最小文本宽 64）仍未冻结，冻结归 V-09 后续轮次，不构成 M1 出口阻塞。

### 4. 保留项

- M0 2026-11-02 验收豁免缺口（逐包人工复核、E2/E4/E5/E7 整项、E3 全量、E6 未测项）保持原状，不因 M1 出口关闭。
- Windows 10、Intel Mac、Linux、最低系统版本、安装/分发、真实 IME/焦点/候选窗、辅助功能文本暴露未测。
- 真实初窗失败收据在锁定 `gpui-pre 0.3.9` macOS 后端下结构不可达（决定 §42），缺口保留。
- 性能门槛未冻结，`first_present` 是屏幕扫描开始的下界；20 次是首轮采样方案。
- 视觉候选数值未冻结；代码块真实横向滚动交互无真实证据。
- 不声称任何 V 项或 AC-15/16 整项通过。

### 5. 文档回填

裁决写入 `docs/decisions.md` 新条目；`docs/v1-architecture.md` §13 的 M1 行与相邻状态段、`docs/v1-validation-plan.md` 的 M1 分项状态段、`docs/development-process.md` §1/§3.1、`AGENTS.md`、`README.md`、`docs/README.md` 与 `openspec/config.yaml` 的当前状态改为「M1 出口已按决定收口（macOS arm64 范围），M2 未开始，V 项/B 类缺口保留」。历史日期段落不改写。

## Risks / Trade-offs

- **出口与整项状态混淆** → 所有回填同时保留四项边界，并在裁决中显式列出「不声称」。
- **把 M1 出口当作发布信号** → 文档状态仍写「内部预览、三平台同发在 M6」，不改变 PRD §9。
- **M2 提前接线** → 本 change 只解锁 M2 入口；W4/W5 仍须等待 V-08 身份/事务方案，且不得以本裁决替代各自任务。

## Migration Plan

仅文档回填，无代码/数据迁移。若用户后续否决任一保留项的处理方式，追加新裁决并保留本轮记录。
