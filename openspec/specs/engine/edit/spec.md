# engine/edit Specification

## Purpose
为 M0 建立从当前只读快照到变更计划或领域拒绝的最小协议，使代表性命令可在真实提交前完成权限、映射、预演与版本检查，后续命令能沿用同一事务边界和错误分类。

## Requirements

### Requirement: 变更计划可验证

计划 MUST 绑定工作版本、补丁、目标源码选区、分组原因及必要前置条件；预演和语义重读 MUST 在真实写入前完成，仅由文档所有者提交。关联 E2/E4、AC-04 基础、R-5、S-7。

#### Scenario: 代表性成功计划

- **WHEN** 对合法普通源码替换或可证明安全的代表性格式命令规划
- **THEN** 返回明确变更；预演验证保留源片段及命令预期语义，纯规划不写 Buffer，一批多补丁只表达一个操作

#### Scenario: 版本或前提改变

- **WHEN** 计划生成后文本/投影/选区上下文改变或预期源片段不符
- **THEN** 拒绝旧计划或重新规划，不用旧范围写入新文本

#### Scenario: 预演失败或预算耗尽

- **WHEN** 重读不满足命令保留契约或预演/补丁数量超过预算
- **THEN** 返回可区别的拒绝/失败/超限，不半提交、不生成空历史

### Requirement: 拒绝完整状态不变

领域拒绝 MUST 保持调用前文本、草稿、待定组、组合、选区、undo/redo 及版本不变；保护与 HTML 约束 MUST 在所有已开放写入口生效。关联 MD-10/11、E4、K-03。

#### Scenario: 保护与 HTML 拒绝

- **WHEN** 可视化修改触及脚注引用/只读区或格式命令触及及跨越 HTML 边界
- **THEN** 返回具体拒绝，完整状态不变；Source 定位作为后续独立意图，不在拒绝时偷偷改变选区

#### Scenario: 允许安全源码编辑

- **WHEN** 源码模式合法修改受保护语法，或直接编辑 HTML 原文
- **THEN** 通过合法补丁协议处理；不把 HTML 格式禁令扩大为源码只读

#### Scenario: 待定输入时拒绝

- **WHEN** 尚有未封口组与 redo 时命令不适用
- **THEN** 不先封口/清草稿/清 redo，再返回拒绝
