# engine/edit Specification

## Purpose
为 M0 建立从当前只读快照到变更计划或领域拒绝的最小协议，使代表性命令可在真实提交前完成权限、映射、预演与版本检查，后续命令能沿用同一事务边界和错误分类。

## Requirements

### Requirement: 变更计划可验证

计划 MUST 绑定工作版本、补丁、目标源码选区、分组原因及必要前置条件；预演和语义重读 MUST 在真实写入前完成，仅由文档所有者提交。关联 E2/E4、AC-04 基础、R-5、S-7。

#### Scenario: 代表性成功计划

- **WHEN** 对合法普通源码替换或可证明安全的代表性格式命令规划
- **THEN** 返回明确变更；预演验证保留源片段及命令预期语义，纯规划不写 Buffer，一批多补丁只表达一个操作

#### Scenario: 版本或前提改变

- **WHEN** 计划生成后文本/投影/选区上下文改变或预期源片段不符
- **THEN** 拒绝旧计划或重新规划，不用旧范围写入新文本

#### Scenario: 预演失败或预算耗尽

- **WHEN** 重读不满足命令保留契约或预演/补丁数量超过预算
- **THEN** 返回可区别的拒绝/失败/超限，不半提交、不生成空历史

### Requirement: 拒绝完整状态不变

领域拒绝 MUST 保持调用前文本、草稿、待定组、组合、选区、undo/redo 及版本不变；保护与 HTML 约束 MUST 在所有已开放写入口生效。关联 MD-10/11、E4、K-03。

#### Scenario: 保护与 HTML 拒绝

- **WHEN** 可视化修改触及脚注引用/只读区或格式命令触及及跨越 HTML 边界
- **THEN** 返回具体拒绝，完整状态不变；Source 定位作为后续独立意图，不在拒绝时偷偷改变选区

#### Scenario: 允许安全源码编辑

- **WHEN** 源码模式合法修改受保护语法，或直接编辑 HTML 原文
- **THEN** 通过合法补丁协议处理；不把 HTML 格式禁令扩大为源码只读

#### Scenario: 待定输入时拒绝

- **WHEN** 尚有未封口组与 redo 时命令不适用
- **THEN** 不先封口/清草稿/清 redo，再返回拒绝

### Requirement: 格式与列表命令保留源码语义

编辑引擎 SHALL 支持 EDIT-08～11 的行内格式添加和取消、空选区配对输入、正文和 H1–H6、引用、有序/无序/任务列表、代码块、数学块、分隔线，以及列表续行、退出、层级调整和任务标记切换。每次成功的结构写入可一步撤销并恢复选区。

#### Scenario: 有序列表续行与空项退出

- **WHEN** 在使用 `)` 分隔符的有序项末尾回车，随后在新建空项再次回车
- **THEN** 首次递增编号并保留分隔符，再次退出列表，嵌套上下文与相邻段落按冻结金样保留

#### Scenario: 格式添加、取消及不安全结构

- **WHEN** 在普通选区应用行内格式、在已格式化内容取消格式，或在空选区触发格式
- **THEN** 保留正文，按操作调整标记和光标；跨越 HTML 边界、触及灰区或无法安全表达的结构操作明确拒绝，原文、选区、草稿与历史保持原状

#### Scenario: 切换任务标记

- **WHEN** 切换可编辑的任务框
- **THEN** 仅改目标完成标记，一步撤销恢复，其他任务项原样保留

### Requirement: 表格结构命令保留源片段

表格 SHALL 支持逐格编辑、行列插入删除和移动、对齐、显式整理、表头调整及整表删除。结构命令保留未涉及的源码字节，成功写入可一步撤销。

#### Scenario: 移动含转义竖线的列

- **WHEN** 移动含转义竖线、行内代码或空单元格的列
- **THEN** 按源单元格边界迁移内容和对应对齐，保留区域外字节，一步撤销恢复原字节和选区

#### Scenario: 表头调整与整理

- **WHEN** 对合法表格执行表头调整或显式整理
- **THEN** 源码和选区符合 V-07 冻结金样；结构不明确、目标过期或复读不符合预期时拒绝，且无部分修改

### Requirement: 全文格式化保全受保护源码

格式化 SHALL 仅规划可安全应用的源码片段补丁，并保留未知语法、HTML 与原文保留区域。

#### Scenario: 文档包含可整理片段与原文保留区

- **WHEN** 按 V-07 冻结风格规划格式化
- **THEN** 安全片段生成确定性差异，受保护片段字节保留；重复格式化无新差异，无法安全格式化时明确拒绝
