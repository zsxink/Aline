# ui/editable-document Specification

## Purpose

规定 M2 单文档从只读阅读进入日常基础编辑时，用户可依源码位置编辑、切换视图、撤销重做和查找替换，并在拒绝或失效时保全当前内容与历史。

## Requirements

### Requirement: 双模式共享单一文档内容

系统 SHALL 在可视化和源码两种模式中编辑同一份 Markdown 源码，使用同一文档选区、当前内容快照与撤销历史。切换模式 SHALL 按源码位置恢复光标或选区，不改变源码字节或产生历史步骤；源码模式 SHALL 支持单选区及剪切、复制、粘贴、纯文本粘贴和全选。关联 PRD EDIT-01/07、AC-02/04/15/20 与架构 §5.2。

#### Scenario: 两模式间切换
- **WHEN** 用户在任一模式产生修改后切换到另一模式并返回
- **THEN** 两模式展示同一当前内容和历史，按源码锚点恢复位置，切换本身不增加补丁、revision 或历史步骤

#### Scenario: 源码基础编辑
- **WHEN** 用户在源码模式选中文本并执行粘贴、纯文本粘贴、删除或全选
- **THEN** 仅合法选择范围通过受检补丁改变源码，选区按同一文档协议更新，可由同一撤销历史恢复

### Requirement: 可视化单块编辑与受检提交

在可编辑文档中，系统 SHALL 允许用户点击可编辑展示块进入编辑，任一时刻至多一个块打开。打开块只持有受控草稿；提交 MUST 预检源版本、源码范围、字符边界和保护语义，并只提交对应单区间补丁，不重建全文。关闭块与提交分离，离块或 Escape SHALL 保留输入并只处理未封口输入组。关联 PRD EDIT-02/03/04/06、AC-02/03/04 与架构 §5.2/5.3。

#### Scenario: 打开、输入并提交块
- **WHEN** 用户点击合法展示文字、在该块输入并提交
- **THEN** 点击经当前投影映射到合法源码位置，草稿提交为基于当前版本的单区间补丁，块尾分隔字节不被误纳入，提交后块可继续保持打开

#### Scenario: 离块或 Escape
- **WHEN** 用户点击另一块、离开编辑上下文或按 Escape
- **THEN** 未封口输入按当前分组协议提交且不丢输入、不重复记步；Escape 不丢弃草稿，其他已形成输入组粒度不被压成整块一步

#### Scenario: 过期草稿或无效映射
- **WHEN** 打开块的基线已过期，或点击命中半字符、越界位置、旧投影或不可编辑区域
- **THEN** 系统拒绝此次写入并保留调用前内容、草稿、选区、历史与有效文档状态，不按旧范围修改新文本

### Requirement: 统一输入历史与可撤销恢复

系统 SHALL 在两种模式中使用同一撤销/重做历史，恢复内容和相应源码选区；相邻普通输入沿用 900ms 分组，IME 确认独立成组。恢复/重载边界、替换和跨块操作不得误并入无关输入。原生 IME 与平台结束等待的接线及平台证据由 `qmd-w5-native-ime-input` 承载，保存/重载基线由 `qmd-w4-persistence-recovery` 承载；本阶段门禁不得绕过这两个契约。关联 PRD EDIT-05/06、SAFE-07、AC-03/04/06 与引擎 §8/9/10。

#### Scenario: 撤销和重做
- **WHEN** 用户撤销或重做一项已提交编辑
- **THEN** 文本与对应源码选区同步恢复；待定组优先按协议处理，拒绝或取消不产生空历史步骤

#### Scenario: IME 或重载历史边界
- **WHEN** 原生组合输入确认/取消，或磁盘内容按冲突流程重载
- **THEN** 组合确认形成独立可撤销组、取消恢复组合前状态；重载建立独立可撤销边界且撤销/重做不回退磁盘基线，行为和平台覆盖按 W4/W5 各自变更验证

### Requirement: 源码查找替换与过期结果保护

系统 SHALL 按源码查找当前文档，两种视图共享命中结果，支持大小写开关、当前项替换和一次操作内全部替换。替换计划 SHALL 绑定当前文档和工作版本；文档变化时 MUST 作废旧结果并在当前快照上重新查找。可视化模式命中不可见源码，或替换范围触及 MD-11 只读展示区时，系统 MUST 先定位到源码模式，再基于当前版本重新计划完整替换操作；不得部分替换或由可视化写入口绕过保护。关联 PRD FIND-01～03、AC-08 与架构 §5.2。

#### Scenario: 查找并逐项定位
- **WHEN** 用户搜索含 Markdown 标记、HTML 注释或链接地址的源码文本并逐项跳转
- **THEN** 结果按源码匹配、显示命中数量和当前项，可视化不可见命中时进入对应源码位置；两模式结果保持一致

#### Scenario: 当前替换或全部替换
- **WHEN** 用户替换当前匹配项或执行全部替换
- **THEN** 当前版本上匹配的范围被受检补丁替换；全部替换作为单一用户操作且可一步撤销，含跨展示块匹配

#### Scenario: 文档变化、空查询或保护区
- **WHEN** 搜索后文档已变化、查询为空、无匹配、文档不可编辑，或可视化替换命中不可见源码/只读语法展示区
- **THEN** 不使用过期选区写入；显示明确空/拒绝状态或先定位源码模式并在新版本重新计算全部目标后执行，不部分修改，不绕过保护规则

### Requirement: 所有写入口遵守保护语义与拒绝零副作用

可视化输入、源码输入、查找替换及 M2 已开放的其他写入口 MUST 共用 Markdown 语义保护与版本校验。领域拒绝、预算/版本失败和取消 MUST 保持调用前文本、草稿、输入组、组合、选区、undo/redo、版本与保存状态不变。关联 MD-11、PRD EDIT-07/FIND-02/03 与 `engine/edit`。

#### Scenario: 受保护语法或 HTML 边界
- **WHEN** 可视化编辑或替换将修改脚注引用/只读灰区，或操作越过不允许的 HTML 边界
- **THEN** 返回可理解的原因且完整状态不变；源码合法修改仍按 PRD 保持可用，HTML 不被扩大成全文只读

#### Scenario: 版本竞争或取消
- **WHEN** 编辑计划/命中产生后版本变化，或用户在发布前取消
- **THEN** 旧计划被拒绝或重新计算，未发生部分写入、历史步骤或错误成功反馈
