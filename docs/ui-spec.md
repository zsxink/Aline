## 1. 用途、范围与权威关系

| 本文标记 | 使用方式 |

## 3. 品牌、视觉基线与尺寸来源

### 3.1 应用身份与默认色

名称统一为 Aline。应用品牌采用[当前透明 PNG](./assets/app-icon/aline.png)：象牙色圆角底板、炭灰 A 与金色丝带；底板属于主体，底板之外透明，不附带白色画布或白边。应用内品牌展示使用此 PNG；macOS 系统图标使用 [ICNS](./assets/app-icon/aline.icns)，Windows 系统图标使用 [ICO](./assets/app-icon/aline.ico)，Linux 使用同一透明 PNG 按平台尺寸派生。macOS ICNS 已含透明安全区，不二次加白底、圆角或额外留白；平台 PNG 和原始母版的用途见[图标使用说明](./assets/app-icon/README.md)。旧品牌 PNG 不再作为参考或回退资源，MarkFlow 图标不进入应用。文件选用已确定，安装后实际显示仍待 V-01；本说明不宣称打包已经接入（PRD §6.1）。

GitHub 白天模式的下列色值直接来自 PRD §6.2；只限定该模式，不强加于其他家族或夜间/护眼模式。

| 语义 | 已确认色值 | 检查位置 |
|---|---|---|
| 编辑画布 | #FFFFFF | 文档空白区、无内容的编辑画布 |
| 正文 | #1F2328 | 段落和默认文本 |
| 次级文字 | #59636E | 辅助说明、次级标签 |
| 边框 | #D1D9E0 | 分区及控件边界 |
| 强调色 | #0969DA | 交互强调、链接及选中提示 |
| 代码底色 | #F6F8FA | 默认代码表面 |

组件消费有效主题的语义样式；主题变化后不能留下旧颜色孤岛。选中、错误、危险和修改状态须有文字、形状、标记或边界辅助，不能仅换颜色。图标在各主题下保持同一操作含义。具体状态色及对比度测量由 V-09 收口，不在本文声称符合任何无障碍等级。

### 3.2 排版、图标与应用外观边界

按 TH-02，编辑画布由 markdown.colors.background 唯一定义，应用 UI 配置不另设 editor 色源；链接唯一用 inline.link.color。内容主题负责正文/源码与 Markdown 块的字体、字号、行高、间距等样式；应用主题负责窗口表面、菜单、侧栏及语义色；高亮开启时，代码配色只替换代码背景、文字、行号和语法色，代码字体、行高与布局仍来自内容主题。按 PL-02，关闭高亮后背景/文字/行号使用当前内容主题的普通代码样式；独立代码主题/模式保留但暂停作用，再启用按当前有效配置恢复。用户显式字号/行高高于主题，分区重置只清该分区覆盖（THEME-05～07、PLUGIN-08、APP-05）。

主题不能改变编辑语义、命令、快捷键、插件开关或任意窗口布局。静态字体加载及中文回退按 V-04 实测；加载失败不能显示“已生效”。透明背景不支持时可用同色不透明回退；不得自行对字体采用无提示忽略。

**语义 token（2026-11-05 方法采纳）：**组件只消费语义 token；原始色值集中在 token 模块并注明来源与用途，组件不得散落十六进制字面量。token 重构不得改变视觉，重构前后截图或像素对比作为审查证据；M1 可先做局部 token 化，不改变主题包 schema、继承规则或已确认视觉。完整 token 集与主题包字段仍按 M4/V-04 收口。

**中文排版（2026-11-05 测量门）：**全角标点避头尾、标点挤压与字体回退、合成斜体是否使用锁定 GPUI 能力或需上游修改，均先由 V-04 夹具和真实渲染测量决定；quiet-md 的 14° 等数值只是参考，不写成 Aline 规范值。未实测前不以伪斜体变形冒充合成斜体，也不在 M1 直接 fork/vendor 上游包。

**2026-11-11 中文排版实测记录（不改变本节边界，V-04 未通过）：** logs 隔离 patched Release 的真实 macOS arm64 窗口取得：普通中文段落的 CJK fallback run 请求 `.SystemUIFont`（Visual）/ `Menlo`（Source），`resolved_family=unknown`、`face_source=Unknown`；首字符 TextSystem advance 为 15.875 / 16.000，拉丁 run 为 4.188 / 9.633；真实 `glyph.position.x` 相邻差（Visual Han 15.860、全角冒号 16.078；Source 16.000）。四字形样本中 CJK fallback advance 与 Han/冒号位置间隔不随 normal/bold/italic/bold-italic 改变，全角标点位置间隔在粗体下变化。字体平滑只有负结果：进程级 `-AppleFontSmoothing 0` 仅改变标题带像素，正文像素 0 变化。**边界：** `advance_px` 是首字符 TextSystem advance，不是 shaped advance；fallback face 身份未解析；正文平滑开/关需要渲染路径改动，属新 scope。未选择 vendor、预折行或接受已知限制，未使用合成斜体；数值仍不是 Aline 规范值。证据 `logs/validation/m1-single-window-readonly/2026-11-11-cjk-06/cjk-linebreak/5_m1_typography/`。

功能图标使用一致的形态、描边和状态体系，含义与名称稳定。图标按钮有可理解名称，悬停和键盘访问均能获得说明；可点击区域不得与相邻操作重叠。悬停、焦点、按下、选中、禁用可分别辨认，焦点不依赖鼠标悬停（PRD §6.3）。主题内置图标风格枚举 outline/filled 已按 TH-05 确认，须完整覆盖动作及状态；图标库、具体形状、描边数值和命中尺寸未冻结，归 V-09，不按旧截图“略大”生成数值。

关闭工作区后标签继续可用，文件侧栏进入无工作区状态，待恢复根记为空（UI-06）；关闭标签与关闭工作区是不同动作。无文档时保留新建/打开入口；没有工作区时提供打开文件夹入口，不能假造一个根目录或示例文件树。工作区恢复路径失效时保留可用无文档窗口并说明。文件夹为空、筛选后无条目、读取失败使用不同文字状态，不统一显示为空白。

## 5. 标签栏、文件树、大纲与状态栏

### 5.1 多文档标签

标签必须区分当前、非当前、悬停、键盘焦点、可关闭和有修改状态。有修改不能只改变文件名颜色。当前/悬停/聚焦标签显示关闭 X；关闭按钮悬停有适应该主题的浅色圆底，焦点有独立可见边界。关闭控件出现不应遮住关键名称或改变其他标签的命中目标（FILE-06、PRD §6.1、V-09）。

标签主体只切换，关闭 X 只发起该标签关闭；关闭未激活标签不能先意外激活再误关相邻标签。关闭后的相邻标签选择及焦点落点作为 V-09 状态样本冻结，不另猜左/右策略。

标签区溢出时横向滚动且隐藏滚动条；右侧新建和列表按钮固定可达。鼠标/触控板滚动映射由 V-09 实测，键盘切换须能揭示目标标签，不能因没有可见滚动条而失去导航。长文件名可截断，但完整名称/路径须可通过鼠标或键盘查看；同名文件有可区分的路径信息（FILE-06～07、PRD §6.3）。

列表顶部固定“全部关闭”，下方**保留一条横向分隔线**；只有文档条目区独立滚动。列表包含全部已打开标签，可识别当前项和修改状态。无标签时批量操作不可执行并有原因，不保留恢复最近关闭标签入口。

切换 Markdown 标签保留内容、选区、滚动、模式和历史；重复打开同一路径复用/定位已有会话（FILE-02～03/07）。标签关闭与批量关闭共用第 12.1 节的保护流程；最后一个关闭后显示无文档状态。图片标签无 dirty，不询问保存。

### 5.2 文件树与文件事务

工作区名称固定在顶部，从左侧内容边距开始，不提供根折叠按钮。标题/文件区悬停或焦点进入时可达新建文件、新建文件夹、刷新、展开/收起子目录四项；键盘不能因默认隐藏而访问不到。只要任一子目录展开，批量项显示“收起”，全部收起才显示“展开”。树内容滚动不带走工作区标题（PRD §6.1）。

文件夹位于同级文件之前，缩进清楚表达层级；具体排序细节/缩进 V-09。默认显示 .md（含 .MD）及 PNG、JPG/JPEG、GIF、WebP、BMP、SVG，大小写不敏感；设置可显示其他格式。不支持的文件不能被强行解码为 Markdown。图片插件关闭时仍显示图片条目，预览不可用并说明原因（FILE-01/04～05）。

| 操作 | 入口/前置与成功结果 | 取消、失败或不可用 |
|---|---|---|
| 展开/打开 | 树条目；目录展开，Markdown 打开/复用，图片按插件打开只读 tab | 读取/解码失败说明原因且不清空其他文档；无效 UTF-8 不提供额外转码入口 |
| 新建文件/目录、重命名、复制副本 | 顶部适用按钮或目标菜单；成功后树更新，重命名同步已打开标签 | 名称/权限/冲突可见；取消不伪造条目；不无提示覆盖 |
| 刷新 | 顶部/工作区菜单；更新实际内容 | 加载/失败与空目录区分；旧结果不能盖回较新树状态 |
| 删除 | 目标菜单，先明确影响及确认，优先回收站 | 取消保留；回收站不可用按 V-08 确定路径，不能自动永久删除 |
| 复制路径、文件管理器显示、关闭工作区 | 目标或工作区菜单按能力提供 | 无路径/平台失败给原因；关闭工作区保留标签，待恢复根记为空（UI-06） |
| 工作区内拖动移动 | 文件/目录到目标文件夹；目标高亮且说明可放置性，成功同步树、所有打开路径、图片预览和工作区状态 | 无效目标不执行；自身/后代拒绝；重名先提示；移动前展示相对资源影响；失败保留源文件 |

拖动过程有源对象、可放置/不可放置目标和结束反馈；不能只靠目标颜色判断有效性。拖出有效范围、取消与冲突尚未解决时不呈现已移动。跨卷/外部拖入、保存交错、回收站不可用按 V-08 形成真实样例，不将浏览器树 DOM 移动当文件事务验收（FILE-09、IMAGE-08、AC-18）。

按已确认 UI-05，文件/目录目标菜单提供键盘可达的“移动到…”入口，打开工作区内目标文件夹选择界面；键盘可选择并确认目标，Escape/取消不移动。成功与失败采用和拖动一致的校验、资源影响提示及路径同步；重名先提示，无效目标不执行。不因此新增文件剪切/粘贴移动或跨工作区范围。入口可达性及事务交错验 V-08/V-09。

按已确认 UI-06，“关闭工作区”只退出该窗口的文件夹上下文，保留 Markdown/图片标签、当前输入、选区、滚动、模式、历史与恢复材料，不触发逐 tab 保存询问。待恢复工作区根记为空，后续未使用新工作区时常规启动不重新打开已关闭根；其他窗口不受影响，不借此重置侧栏布局字段。以后关闭标签/窗口仍按 FILE-08 保护。

### 5.3 大纲与文档定位

大纲按当前 Markdown 标题层级显示，激活标题跳转到对应文档位置，不修改内容/历史（MD-04）。切标签后切换到该文档的大纲，不能停留在另一文档标题。无标题、无文档和图片预览要有可理解状态；异步更新不能拿旧标题跳错位置。

按已确认 UI-03，V1 大纲保留标题层级与点击/键盘主动跳转，不纳入正文滚动反向高亮、自动展开或揭示当前标题，不将这些行为计入当前门禁。主动跳转必须与文档定位一致，切标签更新其所属大纲。目录及脚注导航另见第 8 节与 V-07。

### 5.4 状态栏

编辑模式、外观模式和快速主题是不同维度，名称不得混淆。快速选择与设置/主题菜单同步；手选外观模式关闭随系统，换家族不关闭随系统（THEME-02、PRD §6.1）。

统计在两模式使用相同口径，选区/光标信息不能用 UTF-8 字节数冒充字符列。中文、英文、标点、标记、代码、空白、emoji/组合字符样例待 V-07。异步统计不得把旧文档或旧选区结果显示成当前值；尚未计算与零值要区分。状态栏是否承载保存状态及具体排布由 V-09 样本收口，但第 12 节要求的保存反馈不能省略。

## 6. 编辑模式、滚动与输入连续性

| 场景 | 用户可见要求 | 追踪 |
|---|---|---|
| 切模式 | 同一内容和历史；按源码位置恢复光标/选区并定位相关内容；不能沿用同一像素偏移跳到无关段落 | EDIT-01、AC-02、V-07/V-09 |
| 纵向滚动 | 两模式相同内容列宽、主纵向滚动入口及最右侧滚动条位置；源码无第二根内部纵向滚动条 | PRD §6.1、V-05/V-09 |
| 正文/源码软换行 | 默认开，可关闭；只改变布局，不插入换行或更改历史；长行与横向访问样例须可操作 | APP-02/05、AC-20、V-09 |

## 9. 图片预览 tab

图片预览插件开启时，从树或打开命令选择支持的本地图片进入主内容区只读 tab，与 Markdown 共用标签栏并复用同一路径。它没有编辑光标、Markdown 模式、撤销历史或未保存状态；切换不影响其他文档输入（PREVIEW-01～04、PLUGIN-09、AC-19）。

| 状态/操作 | 可检查结果 |
|---|---|
| 初始加载 | 保留名称/路径与加载状态，不伪装成功或空白文档 |
| 适应窗口 | 默认启用，随视口重算，不放大小图；当前适应状态可辨 |
| 原始尺寸 | 1:1，与适应操作名称不同；高 DPI 实际呈现 V-03/V-09 验证 |
| 缩小/放大 | 1.25 倍步进，10%–800%，显示百分比；到边界不越界且说明不能继续 |
| 平移/滚动 | 超视口可左键拖动平移，正常滚动可用；不引入滚轮缩放手势 |
| 键盘 | 缩小、放大、适应、原始尺寸均可聚焦并执行；滚动和平移可达性验 V-09 |
| 加载失败/超限 | 预览区域错误占位，保留 tab 与路径，不影响其他 tab；错误说明与资源上限验 V-03/V-06 |
| 插件关闭 | 当前图片 tab 转为说明状态，不能继续假装预览可用；不关闭其他文档、不影响内嵌图片 |
| 再启用插件 | 自动恢复仍打开的图片 tab；适应模式按当前视口重算且不放大小图，手动模式在当前文件/视口约束下恢复原缩放并约束平移；资源变化/失败说明并保留路径（PL-03） |
| 关闭 tab | 直接关闭，无保存询问，不写图片像素；再启用插件不复活已关闭 tab，不因此恢复常规重启前 tabs |

插件关闭期间，tab 保留路径、适应/手动模式及视口状态；它们归 tab 视图，不写入全局插件配置，也不扩展重启会话恢复。重新启用需按当前文件/路径重新校验并拒收旧代次任务；资源变化说明与视口约束样本由 V-03/V-09 实测。

## 11. 设置、主题选择与插件配置

### 11.1 设置信息架构

设置为**单一连续纵向滚动页**，固定侧栏分应用设置/插件设置。点击导航滚到对应分区，手动滚动同步选中与位置标题；不能点击分类就替换整页，也不强制整页吸附。分区顺序已确认（APP-01～03）：

1. 应用设置：通用 → 外观 → 编辑器 → 图片 → 高级 → 插件。
2. 插件专属配置随后；代码语言高亮位于整个内容底部。

快捷键一览和关于使用独立弹窗；无配置插件不制造空页。按已确认 UI-01，设置承载于当前主窗口内页面，提供返回编辑入口；返回恢复原文档/标签及编辑上下文，不创建独立设置窗口或模态设置弹窗，连续滚动契约不变。设置全局生效、窗口布局独立的既有边界保持不变。标题/说明/控件关联清楚；Tab 可到控件，导航可键盘激活，滚动定位后不能让标题被固定区域盖住（V-09）。

只呈现 PRD 纳入的设置。通用包括语言/自动保存等已定项；编辑器提供正文/源码与代码换行，代码行号常显；图片路径默认 ./assets，允许相对/绝对路径；高级不能因分区存在就填入 PlantUML 等占位。字号、行高等合法范围待 V-04/V-09，不继承原型所有开关。

有效设置全应用即时生效并持久化，各窗口布局独立。输入错误值须就近指出字段与原因，不能保存后显示一个实际未应用的值；持久化失败与成功有区别。分区重置只清该区显式覆盖，保留不相关分区及文档状态（APP-05）。

### 11.2 外观与主题

外观依次为模式、字体与排版、界面、主题配置，主题配置位于外观分区最下方。首次 GitHub + 随系统；随系统只映射白天/夜间。手选白天/夜间/护眼关闭跟随，换家族保持模式/跟随（THEME-01～03）。

四内置家族 GitHub、Notion、Vue、飞书各三模式；主题卡仅显示当前模式的真实预览、名称、内置/已导入状态、最多五行介绍；悬停或键盘聚焦可读完整介绍。按已确认 UI-02，标题/名称按钮立即应用主题，缩略图独立按钮打开大图；两个控件名称与键盘焦点独立，不能同一次激活既应用又预览。大图有模式名称/状态，左右按钮与方向键切换三模式，Escape 关闭返回触发处；浏览大图或切换预览模式不应用主题、不改文档（APP-03、V-09）。

提供主题 ZIP 导入、打开主题目录、刷新；“打开目录”直接调用系统目录入口，失败说明原因，不能用路径说明弹窗假装目录已打开。刷新反映实际可用主题，缺失/错误与空列表区分。主题导入过程显示处理中/成功/失败，错误定位字段或资源，失败不留半安装、不改原主题；成功不自动应用，普通同 ID 冲突拒绝。V1 不提供同 ID 覆盖升级或应用内删除按钮，用户备份后手工替换/删除目录并刷新（THEME-04～09、V-04）。

主题切换同步设置卡、主题菜单、状态栏、展示区与打开块；保留当前输入、选区、历史。失效活动主题保留原选择身份，渲染回退有效默认并说明原因；修复/重装/刷新/重启后须用户显式选择，不能自动重新应用，也不能覆盖失效期间用户的新选择。重排/资产更新期间不能把旧内容预览当新结果（V-04/V-09）。三模式预览须与实际样式相符，不能同图换标签；预览资源为静态 PNG。

外部插件是后续方向，V1 无第三方安装、商店、脚本或运行时加载入口（PA-01、PRD §8）。本节不替代插件行为规范或主题包格式。

## 12. 交互状态、反馈与错误

### 12.1 关闭、保存与冲突

| 流程 | 必须可见的状态与动作 | 取消/失败后的结果 |
|---|---|---|
| 关闭未保存文档 | 标明文件名/路径及保存、放弃更改、取消；按钮名称不使用含糊“是/否” | 取消保留输入/选区/历史，不关闭当前或后续 tab |
| 关闭其他/全部、窗口、退出 | 按 tab 顺序逐项询问；图片无需保存问询，不能换成汇总式放弃 | 取消、保存失败或冲突未解决立即停止；已完成关闭者不重新打开，当前及尚未处理者保留 |
| 首次保存/另存为 | 路径选择与资源影响明确；真实写入成功后才显示新路径和已保存 | 路径选择取消或资源/写入失败保留内存、临时图片和恢复材料 |
| 常规/自动保存 | 未修改、有修改、保存中、保存失败可区分；较新输入不能被旧版本成功“洗白” | 失败有重试/另存为路径；撤销回已保存内容恢复已保存，恢复写失败单独说明 |
| 外部无冲突变化 | 无本地修改自动重载，保持可定位位置，提示重载来源 | 重载可撤销，撤销只改内存，不倒退磁盘基线 |
| 外部冲突 | 暂停自动保存，展示基线/本地/磁盘差异，载入磁盘、确认覆盖、另存为、取消 | 不自动合并；取消不覆盖磁盘；确认过的磁盘又变化须重新提示 |
| 撤销重载带回旧内容 | 标为有修改，说明来源及自动保存暂停，允许显式保存/另存为或重做 | 不把旧内容自动写回；显式保存成功或重做回磁盘基线后恢复正常策略 |
| 文件删除/不可读 | 明确路径及错误，保留内存，允许重试/另存为 | 不显示成新建空文档，不丢输入 |

依据 FILE-08、SAFE-04～08、TA-01/02、ED-01、AC-05～07、V-07/V-08。系统关闭、菜单退出、窗口按钮及批量操作不得绕过同一保护行为；组合期保存等待按第 6 节执行，关闭交错必须纳入 V-08。

### 12.2 通用控件与反馈分级

每个交互控件按适用性覆盖默认、悬停、聚焦、按下、选中、禁用、加载、成功、失败与取消；不要求给无意义状态编造画面。禁用说明可由附近文本或键盘可读的说明获得，不能只有灰色且靠鼠标悬停才解释。

导航、复制、滚动、打开/关闭菜单、语言或主题切换本身不修改文档字节或制造撤销步；保持文档输入及对应选区上下文，只有明确的定位/选择操作改变可见位置或选区。文本修改命令只影响其明确目标，不能连带改其他标签；文件移动/全局设置等跨目标操作按各自已确认影响处理。上述结果与副作用检查同属验收，不能只检查截图。

| 状态 | 验收要求 |
|---|---|
| 成功 | 只在相应操作真实完成后显示；目标/版本明确，不能与新任务混淆 |
| 失败 | 本地化原因、受影响目标及适用恢复入口；错误不遮断文档继续编辑 |
| 取消 | 与失败/成功区分；内容、选区、历史及资源保留遵循所属事务 |
| 拒绝 | 说明能力/保护边界；文本、草稿、组合、选区与 undo/redo 不变，不产生空步；源码导航为单独动作 |
| 加载/等待 | 目标与阶段可理解，不能显示虚假百分比；已有取消契约的操作保留取消入口 |
| 过期 | 丢弃/重算不能改新状态；格式化/替换等可执行结果过期时明确失效 |
| 插件关闭/当前不可用 | 解释能力来源及恢复方式，保留源码或适用的基础能力，不显示假成功 |

代码复制采用就地勾号而非 toast，错误、保存冲突和需要选择的动作不能只用短暂图标。其余提示承载形式/持续时间用 V-09 状态样本冻结，不锁定某个 Toaster API 或任意动画时间。

按 PRD APP-06，诊断降级汇总作为通用反馈由 UI 呈现，按类别去重并明确当前应用会话、文档身份及文档版本归属。文档关闭时释放所属条目，会话关闭时释放集合；文档版本变化后旧版本结果不得回填或呈现为当前结果。容量受限，具体容量与布局由 V-06/V-09 验证，不在此预设；不展示/持久化正文、IME 候选文本或敏感路径（WC-01）。

### 12.3 图片资源与异常恢复

未命名插图先写该文档独立临时目录，显示图片与引用；首次保存取得路径后按配置复制资源、更新引用再保存。另存为保障应用管理图片可访问，相对目录按新位置，绝对目录保持目标；原文档/资源保留，手写外部引用不静默移动，风险须说明。复制/写盘部分失败或取消不得以坏引用替换当前可用内容，撤销插图只撤销引用（IMAGE-02/07～08、V-08）。

启动发现异常记录时提示恢复/丢弃；恢复先进入内存，让用户决定后续保存位置，不自动覆盖磁盘。多个恢复条目能识别文档及路径，损坏记录的错误不能阻断其他条目；用户逐条选择恢复或丢弃，V1 不显示“全部丢弃”批量入口（WC-05）。未保存、保存取消/失败、异常退出及恢复后未保存均保留恢复材料；关闭取消保留当前及未处理者；明确放弃仅清理该文档不再使用的材料。仍被历史或恢复引用的临时图片不能提前删除（SAFE-08、PRD §5.12 状态表）。

### 12.4 导出与主题导入

导出选格式/选项及输出目标，覆盖已有输出先确认。成功、失败、取消可区分，任务继续时编辑不被阻塞，反馈对应明确文档版本；旧任务不能盖新任务状态。公式/图表采用静态图像的可编辑性边界须说明。组合期导出先可取消等待，完成输入后取当前快照；导出不改源文或历史（EXPORT-01～06、AC-14、V-02）。

主题导入失败显示字段/资源或冲突原因，不切换主题、不留下半安装；成功安装也不自动应用，名称按钮显式应用，缩略图只负责预览。主题预览仅静态 PNG。普通同 ID 冲突拒绝；V1 无应用内覆盖升级或删除按钮，手工目录替换/删除后刷新扫描。失效活动主题保留原选择身份，渲染回退有效默认并说明；修复后不自动恢复应用。字段/schema 细节见[主题包规范](./theme-package-spec.md)，决定依据见[主题决定归档](./archive/2026-10-29-theme-decisions.md)（THEME-08～09、PLUGIN-07、V-03/V-04）。

下表细化 PRD §6.3 的键盘要求及引擎 §8.3 的焦点借还；实际 GPUI/系统可达性、遍历路径和焦点样式待 V-01/V-07/V-09。未实测前不宣称屏幕阅读器全面支持或某个无障碍标准认证。

| 标签/标签列表 | 可切换、揭示溢出标签、访问关闭与新建/列表；关闭后回到存活上下文，不能落在已销毁标签 |

| 菜单/子菜单/右键 | 方向键选择，Enter 执行，左右展开/收起；Escape 先退出当前菜单层级，外部点击/执行后关闭，回到触发上下文 |

焦点、选中和危险状态有非颜色线索；图标有名称，设置字段有标签/说明/错误关联，树展开、插件开关和模式选中状态可理解。内容图片/图表使用已有替代文字、文件名或对象说明；失败不能只展示无名图标，不能凭空生成内容描述。

## 14. 本地化、长文本与窗口适配

zh-CN/en 首发完整支持，默认随系统并可显式选择；所有菜单、按钮、提示、错误、禁用原因、插件说明与弹窗经 t("key") 本地化，内容和文件名不翻译。语言切换即时更新各窗口，保留输入、选区、历史和有效焦点上下文（APP-04、AGENTS.md 铁律 7、Rust §11）。

M1 启动由 app 读取操作系统首选语言列表，只检查列表首项：简体中文映射 zh-CN，英语映射 en；首项缺失或不支持时使用英语并在窗口显示本地化回退说明。catalog 查找仍显式按 `Locale` 实例进行；测试注入只能覆盖映射规则，不能替代系统默认语言的原生启动观测。即时切换控件和完整语言设置仍不在 M1。

按[决定 §24](./decisions.md#24-2026-11-03-验证取证只做中文)，界面语言的人工/原生取证只做中文，不再切换系统首选语言复验英文；双语 catalog 实现与键/占位符自动校验不变。
