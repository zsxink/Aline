# Aline V1 功能清单

> V1 界面与交互的具体验收规范（MarkFlow 覆盖范围、Aline 品牌、浅色主题、代码块控件和 Markdown 展示夹具）见 [ui-spec.md](./ui-spec.md)。

> 供审阅。技术依据见 [engine-design.md](./engine-design.md)。
> 外观与交互参照 MarkFlow（`/Users/xian/Project/book/MarkFlow`）；设置模型、导出主题、图片粘贴、自动保存/外部修改检测等功能语义从它迁移（迁语义不迁代码）。
> **V1 明确不做**：PlantUML、front matter（仅保留防渲染错乱的最小识别，见 v1-architecture §4.2）、纯文本导出、远程图片、协作、Aline 全局主题包的用户自定义、运行时动态加载第三方插件、只读/Preview 模式（可视化模式即可读）、Split 分屏。PDF/Word/HTML 导出与 Mermaid 专属主题导入、自定义属于 V1，见 [plugin-system.md](./plugin-system.md)。
> **待定**：markdown formatter——用户 2026-10-25 的第一版必须清单含此项，但本文既未收录也未列入不做。ElyMark 完全没有 formatter，Aline 需自研；它与保真原则不冲突（格式化是显式用户动作、作用于全文，与"编辑不重排"分工明确），是否进 V1 待补决策。架构位已预留（2026-10-26 复核）：若立项，实现为 aline-edit 的一条全文 `Command`，复用 apart/undo/拒绝协议；决策截止 M3（命令框架冻结前）。
> **HTML（V1 进范围，2026-10-26 裁决 D-13）**：对齐 ElyMark 语义——行内标签映射样式（非浏览器渲染）；HTML 块做浏览器式文本提取（标签消费、文字保留、行内样式生效、注释丢弃、过滤标签的标签本身按字面文本显示），点击显示源码编辑。完整方案见 [engine-design.md](./engine-design.md) §1.10（机制）+ §2.17（落点与里程碑）。

## 1. 文件、标签页与工作区

- [ ] 单文档打开（菜单/拖拽/命令行参数）
- [ ] 打开文件夹：侧栏文件夹浏览器（树形），点击切换文件
- [ ] 浏览器开关：是否显示不支持的格式（**默认不显示**）
- [ ] 点击不支持的格式：提示"不支持的格式"
- [ ] 多标签页：多个打开的文件通过 tab 切换（含关闭、未保存标记）
- [ ] 系统文件浏览器双击 `.md` → 打开**新窗口**，自动定位到该文档所在文件夹
- [ ] 每窗口独立工作区状态（各自的文件夹与标签页）
- [ ] 源码保真：未编辑字节原样写回；BOM/CRLF 风格重放；混合行尾跟随多数派
- [ ] 自动保存（1s 防抖）
- [ ] 外部修改检测（聚焦时检查，弹三方对比）
- [ ] 崩溃恢复（周期性槽位，恢复不自动覆盖文件）
- [ ] 拖放/粘贴插入图片（复制到文档旁 `assets/`，写相对路径）
- [ ] （可选）最近文件/文件夹列表

## 2. 编辑模式（共享同一文本真源与撤销历史）

- [ ] Visual 可视化模式（默认，兼作阅读）
- [ ] Source 源码模式（markdown 语法着色）
- [ ] 模式切换零字节损耗

## 3. 查找与替换

- [ ] 查找（两模式通用，高亮全部命中，Enter/Shift-Enter 逐个跳转）
- [ ] 替换 / 全部替换（= 源码补丁，进撤销）
- [ ] 大小写敏感开关（可选：整词匹配）

## 4. 可视化编辑（阶段 A + B）

- [ ] 点击块就地打开、失焦提交（源码补丁，单步撤销）
- [ ] 点击落点映射到源码字节（转义/标记字符正确）
- [ ] 行内格式 toggle：加粗/斜体/删除线/行内代码/链接（unwrap / wrap / 空选区成对插入）
- [ ] 段落命令：标题 1–6、正文、引用、有序/无序/任务列表、代码块、数学块、分隔线
- [ ] 列表 Enter 续行（序号自增、保留 `.`/`)` 分隔符）、Tab/Shift-Tab 缩进、空项回车退出
- [ ] 表格：逐格编辑 + 行列增删/移动/整理
- [ ] 任务列表勾选框点击切换
- [ ] 撤销/重做（补丁式，连续打字合并为一步）
- [ ] IME 中文输入全程正确（组合过程 = 单步撤销）
- [ ] 标记渐隐（阶段 B：标记符低对比显示）
- [ ] （挑战项，可后移）折叠编辑器 B+：光标所在格式的标记显形、其余隐藏

## 5. 行内与块级元素

- [ ] 行内：粗体/斜体/删除线/行内代码/链接/图片/自动链接/emoji 短代码/脚注引用（上标）
- [ ] 块级：标题/段落/列表/引用（嵌套 + GitHub Alerts 5 种）/围栏与缩进代码块/数学块/分隔线
- [ ] 代码块语法高亮（syntect，按块缓存）
- [ ] 图片：本地相对路径 / `file:` / `data:` URI，异步加载 + 按内容哈希缓存
- [ ] `[toc]` 可点击目录 + 大纲侧栏跳转
- [ ] 行内公式/图片/链接：打开的块内显示源码可直接改（阅读态照常渲染）
- [ ] 块级公式/Mermaid 打开态 = 上编辑 + 下实时渲染（防抖 300ms，失败显示错误面板）
- [ ] 链接/图片编辑弹窗（Ctrl+K / 右键菜单）
- [ ] Cmd/Ctrl+点击打开链接
- [ ] HTML 行内：`<b>/<strong>`→粗、`<i>/<em>`→斜、`<s>/<del>/<strike>`→删除线、`<u>`→下划线、`<mark>`→高亮底色、`<code>/<kbd>`→代码、`<a>`→链接色；HTML 实体解码（`&amp;`/`&#65;`/`&#x41;`）；HTML5 嵌套修复（自动闭合错误交叉嵌套、`<a>` 互斥）；`<script>/<style>/<iframe>` 等过滤标签按文本显示
- [ ] HTML 块：浏览器式文本提取（标签消费、可见文字保留、行内样式在块内生效、`<!-- -->` 注释丢弃、块级标签产生换行、空白按浏览器规则折叠、过滤标签的标签本身按字面文本显示、实体解码、块内 emoji 短代码生效），点击打开 `TextInput` 显示源码原文，提交为单区间补丁（单步撤销）
- [ ] HTML 拒绝制：格式/块命令作用于 HTML 区域或跨越 HTML 边界时返回 `EditRefusal::Html`

## 6. 插件系统（V1 = 编译期内置插件，接口预留动态加载）

- [ ] 插件接口 v1：块渲染器、命令、导出器、i18n catalog 注册；异步资产渲染（缓存键、版本校验与错误降级）
- [ ] 设置页新增插件管理：五个内置插件独立启停，配置持久化；设置项按插件分组
- [ ] 内置插件：数学公式（ratex → SVG）；支持公式背景色设置
- [ ] 内置插件：Mermaid（mermaid-rs-renderer → SVG）；预览、复制、SVG/PNG 导出，支持明暗跟随、内置主题和 Mermaid 专属自定义主题
- [ ] 内置插件：表格增强；行列边界快捷插入按钮和右键增删、复制、对齐操作
- [ ] 内置插件：导出 PDF、Word、HTML；关闭后工具栏和菜单栏导出入口均隐藏
- [ ] 内置插件：代码高亮（syntect）；设置高亮主题与明暗行为
- [ ] 预留插件位：PlantUML（Kroki/本地服务）、图床（上传 → 替换 URL）、更多图表引擎

## 7. 主题系统

- [ ] 主题 = 语义 token 集（背景/前景/强调/边框/语法色/代码高亮/公式与图表色）
- [ ] 每套主题含 **日间 / 夜间 / 护眼** 三模式，一键切换
- [ ] 首发内置 1–2 套主题
- [ ] 数学公式随内容主题色重渲染（缓存键含主题色）；Mermaid 按自身主题设置渲染，选择“跟随明暗模式”时只跟随应用明暗状态，不继承全局主题色
- [ ] 切换即时生效（含正在编辑的块）

## 8. 多语言（内置子系统，非插件）

- [ ] 文案 catalog 机制（TOML/JSON per locale，rust-embed 编译进二进制，按 key 查表）
- [ ] 首发语言：zh-CN + en；默认跟随系统 locale，设置项可覆盖
- [ ] 全部面向用户的字符串走 `t("key")` 查表（含引擎错误枚举的 UI 层翻译、内置插件文案），禁止硬编码
- [ ] 机制在 M2 前定型（错误文案 key 随功能走）
- [ ] （后续）社区语言包可作为插件分发（向 catalog 贡献翻译）

## 9. 性能与容量

- [ ] ≤128KiB 文档全流程无感延迟（同步解析）
- [ ] 块级虚拟化滚动（长文档流畅）
- [ ] >4MiB 自动降级源码模式（阈值可配置）
- [ ] 1MiB 级文档：后台防抖解析 + 增量渲染
