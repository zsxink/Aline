## 拟议规则文本

> Aline 自有直接依赖继续禁止 notify、regex、tokio、Wasmtime/WASI 运行环境和动态插件宿主；单一 Markdown 解析器约束不变。五引擎完整闭包继续无 GPUI，并按现行禁止规则检查。
>
> app/aline-ui/aline-plugin 的 GPUI 闭包可提出精确、可追踪的第三方依赖例外。首批仅限本次隔离审计的 `gpui-pre =0.3.9`。正式 Cargo.lock 中受审 GPUI 子图的包身份、来源、归档校验和、依赖边、target 条件和 features 必须与审计一致；整体 workspace 锁文件允许增加已准入节点并更换临时候选根，但必须重新解析和核查所有实际闭包。GPUI 子图发生变化时重新审计：
>
> 1. 允许其既有 `regex =1.13.1` 路径，以及锁定的 regex 实现包 `regex-automata =0.4.18`、`regex-syntax =0.8.11`；不能借此为 Aline 自有功能直接引入 regex，不能允许五引擎经过其它路径使用它。
> 2. 允许完整 all-target 图保留其 `getrandom =0.3.4 → wasip2 =1.0.4+wasi-0.2.12` 平台绑定路径，但仅在上述依赖边的 WASI p2 条件下。必须保存完整图并证明全部登记桌面目标的实际选包图排除该路径；不得据此引入 WASI 执行宿主、Wasm 插件、Wasmtime 或任何运行期加载能力。
> 3. 对未实际选入的 metadata 过近似路径保留记录，以 Cargo tree 的目标/feature 组合和构建证据交叉核对，不能直接把 metadata 节点存在判作已启用，也不能把 Cargo 解析失败判作未启用。
> 4. 例外按来源、版本、归档校验和、依赖边、target 条件、归属和消费者共同约束。守卫须检查全部实际入边和根路径，不能因存在一条 GPUI 路径就放行同包的其它引入路径。任何版本/来源/features/目标变动、额外命中或新路径均须重新审计；禁止按包名前缀或整个 GPUI 闭包自动放行。

本次不请求放行 `wasi 0.11.1`、notify、tokio、Wasmtime 或第二解析器。`wasi 0.11.1` 只见于 metadata 过近似路径，实际选包图未选入，尚无请求例外的必要。
