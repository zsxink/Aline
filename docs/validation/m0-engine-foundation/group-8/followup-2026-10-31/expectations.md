# 组 8 裁决后补充：独立手写期望

本文件为补充测试的手工输入/结果契约，不从运行输出生成，不替代旧状态表。

| 输入/序列 | 期望 |
|---|---|
| new("abcd\n", 4:4)；new("abcd\n", 4:1) | 打开范围分别 4..4、1..4；反向选区仍为 4:1 |
| 相同字节独立 new 两文档 | SnapshotId 不同；ID 不是内容哈希 |
| x\n 初始快照→输入 a→Undo 待定组 | Buffer SnapshotId 可复用，WorkingVersion 前进，初始身份拒收 |
| 在当前身份登记本文件夹具资源 R1 | dg+1，文本/选区/历史不变；快照强持有 R1 |
| 冻结 S1(R1)→登记 R2→冻结 S2 | S1 仍只有 R1；S2 为 R1/R2；旧身份登记拒绝 |
| 登记跨文档引用或数量超预算 | 错文档/预算拒绝，完整状态不变 |
| 登记 R1→形成历史→Undo/Redo→关闭块→丢 DocCore | 不提前释放 R1；快照仍强持有；最后快照释放后弱观察不可升级 |
| 同文本同版本发请求 Q1、Q2 | Q1 拒绝；Q2 接受；不改输入或历史 |
| 请求 C0→配置代次推进到 C1 | C0 拒绝；C1 新请求接受 |
| 组合期切模式 | 返回 Deferred；完整状态不变；平台自然确认或取消后宿主重试才切换 |
| 非组合期有待定组切模式 | 只提交待定组一步；反向切回不再增历史、文本/选区/版本不变 |
| 组合期 autosave/recovery | autosave 返回 None；recovery 冻结含候选快照，均不结束组合/封口历史 |
| Unix 主机 create-only 写出旧快照后，新输入或关闭目标 | 旧派生结果可拒绝，但 Written 的实际 bytes/基线仍交宿主结算；新输入不被写盘结果覆盖 |

资源边界：宿主必须在资源引用生效前登记所有所需引用；M0 保守持有，不自动发现文本图片或证明空集合无资源。定位值只是宿主解释的标识，未证明文件存在、读取、迁移、删除或恢复记录落盘。

补充预算反例：无草稿但仍开块时，以 4 字节预算请求 5 字节源码 `abcd\n` 快照，必须拒绝且完整状态不变；拒绝不能依赖是否存在草稿。

## 独立复核发现的生命周期反例（修复前先固定）

- 当前身份 Q1 → leave_block → open_block 同范围：源码、WorkingVersion 和 SnapshotId 可以保持，但旧 Q1 必须拒收；关闭边界必须使派生采纳资格单调失效。
- 当前身份 Q1 → Visual→Source→Visual：文本/选区/历史无变化，Q1 仍须拒收；不能因模式回到原值复活旧结果。
- 同模式请求、组合期 Deferred、非法重开、组合期离块、草稿冲突和历史预算拒绝：完整可观察状态不变，派生请求代次不能提前推进。
- 派生请求身份耗尽时，关闭及实际模式切换必须在提交待定输入前受检拒绝；草稿、文本、历史、模式和身份保持调用前状态。
