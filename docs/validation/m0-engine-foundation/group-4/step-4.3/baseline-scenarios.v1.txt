# 4.3 宿主模拟的独立状态预期；先于 Rust 测试手写。
# 本表不模拟文件 I/O、队列或版本 CAS。prepare/encode 均不更新宿主基线。
# 基线身份按对象创建，版本由宿主单调推进；成功只登记实际 bytes，失败保留原基线。
failed-save:
  read bytes=A\r\nB\nC; baseline source=A\r\nB\nC; disk_version=0
  current=A\r\nX\nC; prepare bytes=A\nX\nC; then failure
  baseline id/source/bytes/version 保持原值；current 保持 A\r\nX\nC；saved_input 不变
success-with-newer-input:
  read bytes=A\r\nB\nC; prepare frozen=A\r\nX\nC, bytes=A\nX\nC
  current 继续输入为 A\r\nY\nC；模拟准备 bytes 全部写出成功
  new baseline source=A\nX\nC; bytes=A\nX\nC; disk_version=1; id 必须不同
  saved_input=A\r\nX\nC; current=A\r\nY\nC；较新输入未保存
  再编码 saved_input 也不命中原 bytes（精确源码不同）；编码 new baseline.source 命中
old-baseline-undo:
  read bytes=A\r\nB\nC; 修改后在保存前 Undo 回 A\r\nB\nC，命中原 bytes
  保存 frozen=A\r\nX\nC 成功，new baseline bytes/source=A\nX\nC
  Undo 回 A\r\nB\nC 后只能得到 A\nB\nC，不命中原 bytes，不能恢复过期混合 bytes
  旧 EncodedBytes/旧基线仍可被持有，但不能作为新基线的相等证据传给 encode
protective-bom-save:
  read bytes=A<U+FEFF>B; frozen=<U+FEFF>B; written bytes=BOM+<U+FEFF>B
  new baseline has_bom=true; source=<U+FEFF>B; 再编码精确源码命中实际 written bytes
  恢复 A<U+FEFF>B 后重放新基线 BOM，不能恢复过期无 BOM bytes
actual-write-fact:
  read bytes=A\n; prepared frozen=B\n; 模拟实际成功回执 bytes=C\n
  baseline 必须以 C\n 解码，不能拿 prepared frozen=B\n 代替；saved_input 无可信绑定，置空
  本反例只验证纯宿主示例的结算来源，不声称原语可成功部分写入
reload-and-disk-version:
  old original bytes=A\r\nB\nC; 模拟宿主读取替代 bytes=R\r\nS\r\n，version=1
  old source 编码使用新 CRLF 策略，返回 A\r\nB\r\nC，不能复用旧混合 bytes
  即使新读 bytes 与旧相同，新身份也不同；旧范围被 StorageSnapshot::slice 拒绝
