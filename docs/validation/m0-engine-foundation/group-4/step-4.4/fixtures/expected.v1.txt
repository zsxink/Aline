# 4.4 安全可行性最小反例；在探针实现前按规范独立写定。
# 所有文件仅位于探针独占的临时目录；不访问用户文件。
permissions-only:
  target bytes=OLD\n; mode=0600; xattr user marker=aline-preserve; ACL everyone allow read
  temporary bytes=NEW\n; create_new 独占创建；复制 std Permissions；rename 替换
  待核对预期：bytes=NEW\n，原 ACL 保留；另观察原 xattr 是否保留，不能以 mode 等同 ACL/xattr
copy-path-race:
  target bytes=OLD\n；create_new 临时文件后，将临时路径替换为指向 target 的符号链接
  调用 std::fs::copy(target, temporary) 作为复制权限/元数据方案
  合规预期：不能截断或修改 target bytes，即使复制失败仍为 OLD\n
