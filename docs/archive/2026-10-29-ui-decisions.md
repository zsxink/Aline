### UI-01 · 设置承载方式

- **问题：**设置使用主窗口内覆盖页、独立窗口，还是模态弹窗？
- **背景与依据：**APP-01 定了连续滚动与固定导航，APP-02 只明确快捷键/关于为独立弹窗，没有冻结设置自身的承载。旧原型 README 描述全窗口偏好界面，不能据此决定原生窗口生命周期。
- **影响：**设置进出入口、编辑返回、各窗口共享设置及焦点恢复。
- **可选方案：**A 主窗口内设置页，返回时恢复原编辑上下文（**建议**，贴近旧布局且无需新窗口关系）；B 独立非模态设置窗口，可并行对照文档，但需定义多窗定位；C 模态设置弹窗，进出关系简单，但限制边看文档边调整。
- **是否阻塞：**阻塞 UI 实现中的设置外壳与进出验收；连续页内容和全局设置契约可先推进。
- **暂行处理：**只冻结设置内部结构，不指定窗口类型/尺寸/关闭键；决定后在第 11/13/15 节回填，再验 V-01/V-09。

### UI-02 · 主题卡片的应用与预览动作

- **问题：**主题卡片如何区分“立即应用”与“打开大图预览”？
- **背景与依据：**APP-03 确认真实卡片/大图与左右切模式，THEME-03 确认切换即时；旧 UI §12 同时写“点击卡片立即应用”和“点击进入大图”，缺少命中分工。原型 theme-library.js 的 renderCards/点击处理已分为标题应用按钮和缩略图预览按钮，可作为候选证据，但尚不是当前 PRD 明定的命中契约。
- **影响：**误切换风险、预览焦点和键盘动作，主题列表验收无法唯一确定。
- **可选方案：**A 标题/名称按钮立即应用，缩略图独立按钮/焦点打开大图（**建议**，沿用原型两独立动作且明示名称）；B 单击卡片仅预览，大图内明确应用；C 卡片主体应用，另设卡片旁预览操作。
- **是否阻塞：**阻塞 UI 实现中的卡片命中/键盘分工；主题选择服务、同步与三模式样本可推进。
- **暂行处理：**仅写两个语义动作和已确认的预览行为，不让同一次点击同时套用与预览；V-09 验键盘/名称。若选 B，需评审旧点击即时应用意图及上游表述的回写。

### UI-03 · 大纲是否随正文滚动定位当前标题

- **问题：**除激活标题跳转外，是否要求正文滚动时反向高亮并揭示当前标题？
- **背景与依据：**MD-04 只确定按层级跳转；旧 UI §8 主要描述文件树，原型 interactions.js 存在标题点击跳转，但不足以确认反向同步。请求要求检查两者同步，不能用推测填空。
- **影响：**大纲选中语义、自动展开/滚动、长文导航与视觉验收。
- **可选方案：**A 当前稿仅保留层级和主动跳转，反向跟随后续决定（**建议**，保持最小已确认契约）；B 增加滚动高亮但不自动滚动树；C 高亮并自动揭示当前标题，需约束不打断用户浏览大纲。
- **是否阻塞：**可暂按已有契约推进；阻塞新增反向同步分支的实现/验收。
- **暂行处理：**第 5.3/15 节不将反向跟随计入已确认结果；若选 B/C，建议在 PRD MD-04 补行为并用 V-09 样本验证。

### UI-04 · 完整菜单、工具栏与快捷键清单的确认基线

- **问题：**是否采用第 10.5 节建议清单作为菜单、工具栏与首批快捷键的编排基线？
- **背景与依据：**PRD §6.3 已定顶层结构、门控和平台归属，但未列完整子项/键位；旧 UI §1/10 要求按 MarkFlow 对照，原型 menus.js 含范围外/可选项，不能整体继承。
- **影响：**菜单发现性、工具密度、系统键位冲突与 AC-15 完整键盘验收。
- **可选方案：**A 采用第 10.5 节建议稿并保留其明确列出的 UI-05/06 和 V 验证边界（**建议**，可逐项批改，格式化仍唯一菜单入口）；B 指定特定 MarkFlow 版本/提交的清单作参考，再逐项剔除非基线；C 用户对本表给出差异清单后冻结。
- **是否阻塞：**阻塞 UI 实现中未分配入口/键位的最终编排；已明确入口、命令/门控及 UI 草图可先推进。
- **暂行处理：**第 10.5 节保持建议标记，不把常见软件快捷键自动当 Aline 已确认绑定；已定归属与命令组可推进，确认后仍验 V-01/V-09。

### UI-05 · 文件移动的键盘等价入口

- **问题：**已纳入的工作区内文件/目录移动通过哪个键盘可达入口完成？
- **背景与依据：**FILE-09 明确拖动移动，PRD §6.3/AC-15 要求主要流程可键盘完成；FILE-04 和旧 UI §11 的树菜单没有明确“移动到”或文件剪切/粘贴移动契约。
- **影响：**文件管理键盘可达性、菜单内容和可能的数据破坏误操作；不能只用拖动满足完整验收。
- **可选方案：**A 增加“移动到…”目标选择入口，复用已有目标校验/影响提示（**建议**，可见且不引入文件剪贴板语义）；B 定义文件剪切/粘贴移动及跨工作区边界；C 定义键盘抓取/选目标/放下，减少新菜单但学习成本较高。
- **是否阻塞：**阻塞 UI 实现中的键盘移动入口与该项 AC-15 验收；拖动及事务校验可推进。
- **暂行处理：**不擅自新增入口或快捷键；确定方案后建议补 PRD FILE-09，再用 V-08/V-09 验冲突/取消/焦点。

### UI-06 · 关闭工作区时已打开标签的去向

- **问题：**“关闭工作区”是否关闭该窗口全部标签，还是仅退出文件夹上下文并保留已打开标签？
- **背景与依据：**FILE-04 纳入关闭工作区，FILE-07/08 规定标签保留/关闭保护；没有明确工作区关闭与标签的连带关系。旧 UI §11 只列动作名称，原型不能证明文件会话契约。
- **影响：**是否触发逐 tab 保存保护、无文档/无工作区状态和工作区偏好恢复。
- **可选方案：**A 仅关闭文件夹上下文并保留标签（**建议**，减少隐式关闭，需明确偏好变为空）；B 关闭整个工作区及其标签，沿 FILE-08 逐项保护，取消时需定义工作区是否仍保持；C 关闭工作区时额外询问保留/关闭标签，灵活但增加每次决策。
- **是否阻塞：**阻塞 UI 实现中的关闭工作区动作；独立标签关闭和常规启动契约可推进。
- **暂行处理：**保留该已纳入动作的规范位置，不选择连带结果；实现此动作前裁决，建议补 PRD FILE-04/07 并回填 V-08/V-09 样本。
