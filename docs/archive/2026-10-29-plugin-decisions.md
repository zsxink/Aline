### PL-01 · 导出开关是否同时控制 Mermaid 独立图像操作

- **问题：**Mermaid 开启、导出插件关闭时，图表菜单的 SVG/PNG 导出与图像复制是否仍可用？
- **背景与依据：**PRD PLUGIN-01/EXPORT-06 把这些能力放在 Mermaid 图表菜单；PLUGIN-03/UI §10.5 将 export 开关对应 PDF/.docx/HTML 入口。旧插件稿 §5 又称关闭导出后“所有导出入口消失”。架构 §4.3 的 export/diagram 是产物服务归位，不能决定产品门控。现有 TA/ED/UI/PA 问题没有裁定该组合；V-02/03 覆盖样本但不替代门控选择。
- **影响：**能力声明、菜单/执行检查、剪贴板、任务关闭依赖及 AC-11/14 的组合期望。
- **可选方案：**A（**建议**）：Mermaid 自己控制 SVG/PNG 和图像复制，export 只控制三格式正文导出，可共享产物服务。B：SVG/PNG 同时要求 export 开，图像复制仍仅要求 Mermaid。C：SVG/PNG 与图像复制均同时要求两插件开启。A 的职责更贴近 PRD 插件卡；B/C 的集中门控较强，但需明确跨插件依赖及用户说明。
- **是否阻塞：** **阻塞插件实现（仅该交叉门控分支）**，不阻塞三格式正文导出和 Mermaid 基础渲染。
- **暂行处理：**本稿只固定 Mermaid 关闭无图像命令、export 关闭无三格式入口；不为争议组合写默认门控。产物计算/单一发布可先按已有边界设计。裁决后回写 PRD PLUGIN-01/03、EXPORT-06、UI §10/11 及 V-02/03 用例。

### PL-02 · 关闭代码语言高亮后的普通代码配色来源

- **问题：**高亮插件关闭时，普通代码块的背景、文字及行号颜色回到内容主题，还是继续使用保留的独立代码主题/模式？
- **背景与依据：**PRD PLUGIN-05 明确普通代码与核心控件保留，PLUGIN-08 明确独立两维代码配色；当前 UI §3.2/11.3 未说明两者在关闭状态如何组合。旧插件稿 §3.5 指向 Markdown 主题，历史主题稿允许 highlight.json 覆盖代码表面，不能以历史任选其一。无既有待决编号裁定；V-02/04/09 尚无该状态的确定期望。
- **影响：**关闭回退渲染、颜色解析所有权、主题切换/缓存、导出普通代码样本及 AC-11/12。
- **可选方案：**A（**建议**）：关闭后使用当前内容主题的普通代码表面，独立代码配置保留但暂停作用；再次启用恢复。B：仅关闭语法 token 着色，继续采用独立代码主题/模式的背景/文字/行号。A 与旧插件回退语义一致、禁用边界清楚；B 保留用户阅读配色，但配置隐藏时仍影响表面，需要明确解释。两者均须保留行号/复制/语言/编辑和核心 Markdown 着色。
- **是否阻塞：** **阻塞插件实现（仅关闭状态的普通配色解析）**，不阻塞语言着色、核心控件或开启时两维配色。
- **暂行处理：**只固定“无语言语法色”和配置不丢，不按旧稿冻结表面色；导出矩阵相应格保留待定。裁决后回写 PRD PLUGIN-05/08、UI §7.2/11.3，并交后续主题专项及 V-02/04/09。

### PL-03 · 图片预览再启用时已有 tab 的视口恢复

- **问题：**图片预览关闭后再启用，保留的说明 tab 应如何恢复预览及其缩放/平移？
- **背景与依据：**PLUGIN-09/PREVIEW-01～04、UI §9 已决定关闭保留 tab/路径并显示说明；PREVIEW-02 只规定初次适应窗口，AC-11 要求再启用正确。配置保留不等于 tab 视口保留，FILE-07 也不能推导图片视口重建策略；旧插件稿未包含图片预览。没有既有 UI 待决编号涵盖此选择。
- **影响：**tab 状态归属、重新解码/布局时机、失败重试、AC-11/19 的再启用期望；不涉及重启恢复 tabs。
- **可选方案：**A（**建议**）：再启用自动恢复仍打开的 tab，适应模式按新视口重算，手动模式在当前文件/视口约束下恢复原缩放并约束平移；资源变化/失败说明且保留路径。B：自动恢复，但统一重置为适应窗口。C：保留说明，用户再次打开图片时恢复预览并按初始适应。A 保持阅读位置但状态/重排更复杂；B 简单但失去手动视口；C 降低自动加载成本但增加一步操作。
- **是否阻塞：** **可暂按已有契约推进**；仅再启用已有 tab 的状态转换及对应 AC-11/19 用例须等裁决。
- **暂行处理：**先实现只读 tab、初始适应/缩放/平移、关闭说明、路径保留和过期结果拒收；不假定自动恢复或重置。裁决后回写 PRD PLUGIN-09/PREVIEW、UI §9 和 V-03/V-09 样本。
