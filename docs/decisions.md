## 2. 状态、编号与维护纪律

| 已被取代 | 原结论全部或部分不再适用；注明替代来源、范围、确认时间或本轮复核时间 |

### D-2026-10-26-01

- **日期 / 类型：**2026-10-26（旧记录日期；非本轮重确认） / 架构约束 / 技术选型。
- **当前状态：**有效（替换边界）；仅供参考（签名）。
- **当时决定、背景与理由（旧原文）：**

> - **D-2026-10-26-01 · Buffer trait 按"rope 可实现"定形**：trait 不出现任何返回 `&str` 借用的方法（ropey 给不出任意区间的连续 `&str`）；`text()/slice()` 返回 `Cow`，`slice` 越界/非 UTF-8 边界返回 `None`（坐标 bug 显式暴露，不 panic），新增 `for_each_chunk` 零拷贝遍历。v1 仍 StringBuffer，v2 换 RopeBuffer 不改签名。（engine-design §2.2）

- **本轮复核：**保留可替换缓冲与受检字符/范围边界；Cow、Option、for_each_chunk 和 V2 换 rope 不是已冻结公共 API。StringBuffer 是建议起点，不预装 ropey。
- **影响范围：**buffer/markdown/edit，M0 API。
- **回写位置：**[引擎 §4/9/18.1](./engine-design.md)、[架构 §3.2](./v1-architecture.md#32-栈与依赖的状态)。
- **验证状态：**V-05/07；无 trait 实现验证。

### D-2026-10-26-05

- **日期 / 类型：**2026-10-26（旧记录日期；非本轮重确认） / 架构约束。
- **当前状态：**已被取代。
- **当时决定、背景与理由（旧原文）：**

> - **D-2026-10-26-05 · dirty 用 undo 栈深判定，不用 stamp**：`dirty = history.undo 栈深 != saved_at || open 有未提交修改`。undo/redo 是精确逆补丁，栈深回到保存值 ⟺ 内容与已保存字节一致（O(1)）；stamp 会把"打字后撤销回原文"误判为 dirty。保存动作隐式封口当前打字合并组。（engine-design §2.9、v1-architecture §6.3/§15.2、architecture-guide §5.7）

- **本轮复核：**同深分支、历史裁剪和组中途保存均反驳栈深等价；dirty 取实际保存内容的等价事实并含草稿，保存不封口。快速内容身份/等价算法仍是实现方案。
- **影响范围：**History/保存/关闭 guard，M0～M2。
- **回写位置：**[引擎 §9.3](./engine-design.md#93-历史保存点及重载)、[架构规范 §15.1](./architecture-guide.md#151-所有权保存状态及外部变化)。
- **验证状态：**V-07/08；无算法实测。
- **取代 / 关联：**TA-01/02（2026-10-29）；MIG-R01 登记栈深修正，非伪造旧用户裁决。
