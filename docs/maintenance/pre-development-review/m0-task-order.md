# M0 建议任务顺序

2026-10-30。本附件是终审后的执行建议，**不是本轮实施授权或新增产品规范**。本轮未执行下列任务；阶段依据为 PRD §9、架构 §13、引擎 §15、Rust §19。后续开始 M0 时按此顺序取证，具体 API 可在保持现行契约的前提下调整。

## 1. 先登记兼容目标与工具、依赖可行性

- **目标：**形成可复现候选环境及准入账本，优先暴露 GPUI 与禁用依赖闭包之间的潜在不兼容。
- **crate：**全八 crate；重点 app/ui/plugin 的 GPUI 闭包与五引擎的无头闭包。
- **前置：**采用当前 PRD/AGENTS 和已确认决定；不要求 V-01 全平台实验先通过。
- **关键不变量：**单一来源且精确锁定 `gpui-pre`；旧 `=0.3.9`、edition 2024、历史 MSRV 都只是候选。notify/regex/tokio 等禁令按 Rust S-13-06/S-15-02 覆盖直接、传递、dev/build、目标与 feature 路径，不得私自改成“仅直接依赖禁止”。
- **验证：**核对实际锁定源码/API、Rust/Cargo/rustfmt/Clippy/edition 组合、必要平台补丁、许可证和所有目标解析图；按 V-01 登记 macOS、Intel Mac、Win10、Linux 的目标与可用取证设备，区分拟支持和已实测。这里只登记目标，不违背先 macOS 后 Windows/Linux 的实验顺序。
- **完成标准：**候选组合有可检查的版本/来源/闭包证据；未准入后端不预装。若实际闭包违反禁令且无合规候选，停止依赖该组合的接线，记录精确冲突和最小替代/裁决路径；不得把本终审结论当豁免。
- **回填：**架构 §3.2、引擎 §18.2、Rust §2/13/19；V-01 目标栏及依赖变更记录。此步骤不标 V-01 整项通过。

## 2. 建最小八 crate 骨架、有效工程门禁与 catalog

- **目标：**职责可编译、无头边界可失败检查；不一次性生成架构目录里的全部空模块。
- **crate：**app、aline-ui、aline-plugin、aline-edit、aline-markdown、aline-buffer、aline-source、aline-app-core。
- **前置：**步骤 1 的候选组合合规，新增依赖逐项准入。
- **关键不变量：**source 独立；buffer 不依赖 source；app-core 无 GPUI；五引擎零线程/零可变全局状态。所有自有代码默认 unsafe forbid；引擎所有 targets 禁 unwrap，生产代码遵守 RS-03。文案从第一天走显式 locale 的 `t(key)` 与 zh-CN/en TOML + rust-embed。
- **验证：**基于实际 Cargo metadata 的直接/传递方向检查；成员 lint 继承及最小正反例；rustfmt 选项确实生效；catalog 键与插值一致、错误枚举不携带 UI 文案。建立可执行测试发现入口，根 fixtures 不能假装自动执行。GPUI 测试 harness 名称/能力须核对锁定源码。
- **完成标准：**fmt/clippy/test 三条完整命令可运行并通过，结构检查能对故意反向依赖、GPUI 泄漏和禁用库失败，负例移除后再通过；逐项 lint 配置记录适用层。工程 CI 后续按 Rust §2.3 接线，不能用本轮文档检查结果冒充已有 CI。
- **回填：**Rust §2/17/19，架构 §4/10.3；实际工程检查入口和未自动化规则的人工步骤。

## 3. 冻结坐标、身份与公共输入输出边界

- **目标：**先决定类型的 home 和语义，防止实现映射时再引入反向依赖。
- **crate：**buffer/markdown/edit/source/app-core；ui 的 DocCore 契约。
- **前置：**步骤 2 的无头构建与依赖检查有效。
- **关键不变量：**持久位置仅为源码 UTF-8 边界；跨模块源码/绘制/UTF-16 范围分型；源存储坐标独立。tuple 补丁形状不变，但仅由受检边界进入。DocumentId、revision、draft generation、DiskVersion、投影身份不混用，草稿代次取消后也不复用。
- **验证：**公开 API 消费测试、非法边界/错版本/错投影拒绝；source 接受自身元数据及文本视图，不导入 buffer/UI 快照类型；UI 不手算局部偏移或 UTF-16 表。
- **完成标准：**类型归属、版本/范围/错误语义均有唯一维护处；恒等与多对一映射都经统一入口；不存在为复用类型增加的循环依赖。
- **回填：**Rust §5、引擎 §3/4/7、架构 §4/5/7.1；V-07 的接口验证记录。

## 4. 先证明 source 字节与行尾表示能往返

- **目标：**在 source↔buffer 表示冻结前解决保真金样，不能直接把 LF 表示建议当已证明算法。
- **crate：**aline-source；由独立测试驱动 buffer 边界输入。
- **前置：**步骤 3 的存储/源码边界与相等证据语义。
- **关键不变量：**有效 UTF-8 唯一编码；BOM 与原 bytes 保留；未改逐字节返回；改后只重放 BOM/行尾多数派，平票 LF；不吞孤立 CR、不补末尾换行。encode 后 decode 必须与冻结源码等价。
- **验证：**空文件、BOM、LF/CRLF/混合平票、孤立 CR、无尾换行、无效 UTF-8、有效 UTF-8 的 `%PDF`/`PK` 开头；加入 `\rX\n` 删除 X、边界插入/删除/粘贴形成 CRLF 的反例。对每个被接受操作核对源码、字节、逆操作与再解码，失败不得静默丢字。source 的受检 I/O 只做最小原文件保全故障样例，不提前宣称全平台原子保存。
- **完成标准：**原 bytes 通道、内容回到基线、混合行尾例外和边界组合均有独立期望；候选表示不能自洽则先修设计，不向 UI 固化接口；不以拒绝正常基线输入作为缩减范围捷径。
- **回填：**引擎 §5、架构 §5.1、V-06/V-07 编码金样；权限/替换平台保证仍留 V-01/V-08。

## 5. 实现 buffer 原子补丁、锚点与历史原语

- **目标：**建立后续所有写入的唯一受检基础。
- **crate：**aline-buffer。
- **前置：**步骤 3/4 的坐标、源码表示和内容身份。
- **关键不变量：**同基线升序、不重叠、合法 UTF-8；整批应用或整批拒绝。正补丁属 before，逆补丁属 after；保存内容身份不是历史栈深；Undo/Redo 推进 revision，禁止回退磁盘基线或写盘。
- **验证：**插入/删除/替换/多个变长补丁的手工金样和随机往返；非法端点、重叠、旧基线拒绝时全文/选区/history/redo 不变；保存 A→撤销→输入 B 同栈深、裁剪历史、内容重返基线、资源引用存活接口。属性测试库先准入，不因候选 proptest 自动添加。
- **完成标准：**补丁与逆补丁恢复精确内容/选区，锚点变换有规则，输入组/重载边界可表达，拒绝无空步；不在每键路径做全文指纹。
- **回填：**引擎 §9、架构 §5.4、Rust §12，AC-01～04 基础证据与 V-07 对应用例。

## 6. 建唯一解析管线、块/Gap、映射与保护区间

- **目标：**可以无界面 dump 展示树、原始范围与降级诊断。
- **crate：**aline-markdown，消费 buffer 的公开只读边界。
- **前置：**步骤 3～5；pulldown-cmark 精确版本/features 已准入。
- **关键不变量：**唯一解析器；Cargo features 与运行期 Options 分开登记；改写仅解析副本且带回原文映射；字面区域避让；块尾分隔属 Gap。显示字符对齐稳定，不要求每个源码字节双射；MD-11 与 HTML 语义独立于样式。
- **验证：**CommonMark/GFM 与产品定制夹具；实体/转义/emoji/组合字符/UTF-16、隐藏注释/标记、空文档、嵌套与未闭合输入；块+Gap 覆盖、映射非法边界、旧投影、脚注引用子区间及普通正文可编辑边界。预算在读取/扫描中检查，超限保留原文并返回类型化诊断。
- **完成标准：**基础 PRD 语法和保护识别的金样可执行，stand-in 碰撞等失败可恢复；实际预算值明确为实验参数。公式/图表渲染支持不因语法识别完成而通过。
- **回填：**引擎 §6/7/11/12、V-06/V-07 基础夹具，解析配置和 AC-03/09 的基础证据。

## 7. 建 Change/拒绝与最小编辑协议

- **目标：**用少量代表性命令证明快照→计划→预演→重验→原子应用的完整路径。
- **crate：**aline-edit，消费 markdown/buffer 公开 API。
- **前置：**步骤 5/6 的补丁、匹配版本 Parsed 与保护范围。
- **关键不变量：**Change 带工作版本、目标选区、补丁和分组原因；失败保当前全文、待定组、草稿、组合与历史。可视化保护不能靠整块布尔锁死脚注所在普通段落；HTML 格式拒绝与原始源码编辑分开。
- **验证：**成功/无改动/错版本/越界/保护触及/预演失败；正文与脚注引用交错、源码可改、拒绝后的定位动作另行执行；查找计划作废接口和一次多补丁历史可表达。命令风格、表格/格式化全能力仍按 M3/V-07 收口。
- **完成标准：**没有绕过 DocCore 的公开可写通道；拒绝零副作用可由状态对比证明；基础协议不迫使后续重开 TA/ED。
- **回填：**引擎 §8/9/14、架构 §7.1/7.2、V-07；记录 AC-04 基础覆盖与未覆盖结构命令。

## 8. 无窗口驱动唯一草稿、输入组与当前快照

- **目标：**验证 DocCore 纯状态协议，给 M2 的真实输入/保存编排提供可消费边界。
- **crate：**aline-ui 的纯状态部分 + buffer/edit/app-core；不向引擎引入 GPUI。
- **前置：**步骤 3～7。
- **关键不变量：**Buffer+唯一草稿为当前内容；900ms 输入组与开关块分离；IME 确认独立、取消恢复且代次失效。快照不封口；显式发布等待平台自然结束可取消，自动保存延后，恢复保护当前输入为独立协议。
- **验证：**虚拟时钟/事件序列驱动同块多组、离块、Undo/Redo、组合更新/确认/取消、快照与等待取消交错；旧映射和关闭实体结果拒收。保存点与磁盘基线分开建模，资源只表达可达引用和在途所有权，不提前实现全文件协调器。
- **完成标准：**M2 可复用同一状态协议，无子编辑器第二历史；真实 IME、焦点和平台 callback 未测项明确。若当前锁定 GPUI 不支持预设测试 harness，登记替代的实际可用分层验证，不伪造通过。
- **回填：**引擎 §8～10/17、架构 §5/7.1、V-07/V-08 身份与输入协议设计；真实平台部分保留未执行。

## 9. M0 出口复核与 M1 交接

- **目标：**形成可重跑的基础正确性证据和下一阶段阻塞清单。
- **crate：**全 workspace；重点五引擎无头闭包。
- **前置：**步骤 1～8 的实际记录和失败已处理。
- **关键不变量：**基础 AC 用例不等于 AC 全通过；M0 不替代 M1 原生、M2 安全闭环或三平台发布门禁。候选失败不静默改产品结果。
- **验证：**完整 fmt/clippy/test、架构依赖/安全/catalog 检查、金样与敌意输入；可检查的展示树/范围 dump。登记工具、设备、输入、步骤、实际结果和未覆盖平台；人工检查与自动检查分列。
- **完成标准：**架构 §13 M0 出口逐项有证据；V-01 目标、V-06/V-07 基础部分及 M0 工具实验可单独复查；没有被“整项V未执行”掩盖的失败，也不把局部成功写成 V-01～09 全通过。
- **回填：**验证计划分项证据、Rust §19、架构/引擎阶段出口。M1 排入原生 macOS 冒烟、字体/中文回退 V-04、真实夹具和 V-05 基准；M2 前形成 V-08 身份/事务方案，M2 出口实测最小安全闭环。
