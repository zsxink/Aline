# Aline 开发前独立终审报告

日期：2026-10-30（Asia/Shanghai）。范围：审计与必要文档修订。本报告是维护审计，**不是产品规范、技术实验结果或开始实现的动作**。

## 1. 结论

**可以进入 M0：本轮必要修订完成后，没有发现启动 M0 的文档阻塞。** 当前文档足以约束 M0 的依赖取证、工程地基、纯逻辑金样与接口设计；这不表示所有实现设计已经冻结，也不证明 GPUI/原生平台/文件事务/资源后端可行。

M0 内必须完成：工具链/edition/精确 GPUI 及完整依赖闭包准入、有效 lint/依赖/安全/catalog 检查、坐标类型 home 与版本/投影身份、source 保真表示（含孤立 CR 拼接反例）、before/after 补丁与历史、块+Gap/映射/保护区间、无头输入组/快照协议与测试 harness。具体顺序及每项七个执行要素见 [M0 任务顺序](./m0-task-order.md)。

V-01～V-09 全部仍未执行。它们按领域/阶段逐项阻塞相应实现冻结、阶段出口或正式发布；无需在 M0 启动前全部完成。**M2 必须实证编辑→保存→外改/可撤销重载→恢复与未命名临时图片的最小安全闭环**，不得后置 M4/M5。正式 V1 仍须 macOS→Windows/Linux 实测，三平台门禁通过后同发，Win10/Intel Mac 必须目标保持。

本轮未创建应用代码、Cargo workspace、依赖配置、Rust 工具链文件或 CI；未恢复/重建 docs_bak/、reports/；未改既有确认原话，也未提交 Git。

## 5. 需求与证据追踪结论

全部 89 编号需求（FILE9/SAFE8/EDIT14/FIND3/MD11/IMAGE8/PLUGIN9/EXPORT6/THEME9/APP6/FORMAT2/PREVIEW4）有可定位的架构主责、专项行为及 AC/V/阶段；未发现编号虽存在但正文完全悬空的基线行为。具体失败出口在[逐项表](./requirement-trace.csv)单列，[AC/V 表](./traceability.md)指出局部阶段与整项完成的区别。

正文交叉结果：source 独立、app-core 零 GPUI、五引擎无线程/可变全局；Buffer+唯一草稿与不可变投影、块尾/Gap、before/after 补丁、RS-02 类型边界与映射身份一致。未编辑原 bytes、编辑后 BOM/多数派例外、输入组与开合分离、IME 取消/ED-01 自然等待相符。保存点/磁盘基线分开，重载 Undo 不退磁盘基线，取消/失败保输入、历史和资源，在途 I/O 要结算而不能只丢回调；路径/关闭/恢复不另维护状态副本。

六插件责任/配置/启停回退、Mermaid 独立门控、主题封闭字段/逐叶继承/唯一色源/静态资源/安全安装/失效显式重选、降级汇总会话所有权/版本/隐私/容量/释放均有正文承接。菜单/键位/主窗设置/中英文/键盘访问有已确认基线，原生能力继续待 V。

确认核对：Q-01～21（含 Q-19 补答）；TA-01 A/TA-02 B/TA-03 A；PA-01；RS-01～05/ED-01/UI-01～06/PL-01～03/TH-01～10/WC-01～07/PROTO-01～06 均沿确认归档，未重开或改写原话。WC-07 只是 W22～24 缺项占位，未补造提案；Zed 主线 API、旧 300ms/SQLite 会话/主题 watch/固定宿主、WordCraft 的旧通用 catch/签名拒收/全部丢弃/设默认/恢复后置均未自动立项。
