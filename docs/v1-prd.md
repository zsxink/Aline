## 2. 产品定位与目标

Aline 是面向本地 Markdown 文件的桌面编辑器，采用 Rust + GPUI 原生界面，无 WebView。默认在可视化文档中阅读和写作，也能随时切换源码模式。用户继续拥有普通 Markdown 文件，无须把内容迁入专有数据库。

主要用户是使用 Markdown 写技术文档、学习笔记和长文的人，尤其是需要中文输入、代码、表格、公式和图表，同时关心文件兼容性与原文保留的用户。

V1 要解决四件事：

1. 打开本地文件即可阅读、修改和保存，不必在编辑器与预览窗口之间往返。
2. 常见写作操作可通过键盘、工具栏和上下文菜单完成；复杂内容始终能回到源码编辑。
3. 保存、撤销、模式切换和异常恢复行为可靠，不无故重排用户的 Markdown。
4. 日常文档输入和滚动顺畅，长文档有明确降级策略，不因图表、图片或异常语法失去响应。

V1 不以完整复刻 Typora 的全标记隐藏体验为前提。基础交互采用“点击块进入编辑、提交后恢复展示”，编辑时保留低对比度标记；进一步隐藏非光标处标记列为可选项。

## 4. 核心用户流程

### 4.1 打开并继续写作

用户从打开菜单、拖入文件或命令行参数打开 Markdown，也可打开文件夹后从树中选择文件。文档默认以可视化模式呈现；点击段落进入就地编辑，输入中文、调整格式，切换源码检查原文，再保存。切换视图不会产生编辑，保存成功后显示已保存状态。

### 4.2 多文档写作

用户在同一窗口打开多个文件，通过标签或已打开标签列表切换。不同文档的内容、选区、滚动位置和撤销历史相互独立。同一路径在同一窗口复用标签，已在其他窗口打开则定位已有文档，避免重复编辑。关闭全部或退出时，逐个标签询问是否保存，取消后停止后续关闭。

### 4.3 插入图片、公式和图表

用户将本地图片拖入文档或粘贴截图，成功写入资源文件后插入引用；未命名文档先写入临时目录，首次保存时再复制到配置的资源目录并更新引用；编辑公式或 Mermaid 时，上方显示源码，下方更新预览。资源加载或渲染失败时，用户仍能阅读错误、复制或修改源码，继续操作其他内容。

### 4.4 处理外部变化与异常退出

文档在其他工具中被修改后，本地无修改时自动重载；有冲突时提示用户选择处理方式。异常退出后，下次启动发现恢复内容，用户可以查看并恢复到内存，再决定保存位置。恢复过程不会直接覆盖磁盘文件。

### 4.5 调整外观并交付文档

用户在设置中选择主题与模式，或为代码块独立选择配色；当前文档内容和编辑状态保持不变。用户通过导出选择格式、设置输出选项和目标位置，成功后得到可打开的文件，失败则保留当前文档并说明原因。

## 5. 功能需求

### 5.1 文件、工作区与标签

| 编号 | 要求与验收结果 |
|---|---|
| FILE-01 | 支持新建未命名文档、打开本地 Markdown、保存及另存为。Markdown 扩展名按大小写不敏感识别 `.md`，包括 `.MD`。首次保存由用户选择路径；取消对话框后内容和编辑状态不变。 |
| FILE-02 | 支持菜单、拖放、命令行参数打开文件。系统文件管理器双击未打开的 Markdown 时新开窗口并定位所在文件夹；同一路径已打开时优先定位已有标签/窗口，不创建可独立写盘的副本。 |
| FILE-03 | 每窗口拥有独立工作区、标签和布局；应用设置全局共享。同一文档只有一个可编辑会话，重复进程的打开请求转交现有应用，避免多进程互相覆盖。应用注册为 Markdown 文件的打开候选，并提供用户前往系统设置选择默认应用的指引；不提供应用内“设为默认”按钮，也不自动更改系统默认应用。三平台关联与指引能力按 V-01/V-09 验证。 |
| FILE-04 | 文件树支持目录展开/收起、打开、新建文件/文件夹、刷新及批量展开/收起；文件夹排在文件之前。提供重命名、复制副本、删除、复制路径、在文件管理器中显示、关闭工作区；重命名同步打开标签，删除优先系统回收站并确认影响。关闭工作区仅退出该窗口的文件夹上下文，保留全部已打开标签、输入/选区/历史及恢复材料，不触发逐 tab 保存询问，不影响其他窗口，不重置无关侧栏布局字段（UI-06）。 |
| FILE-05 | 文件树默认显示 Markdown 和 PNG、JPG/JPEG、GIF、WebP、BMP、SVG，扩展名大小写不敏感；默认隐藏其他格式，设置可显示。图片预览插件启用时图片打开只读 tab；关闭后保留图片条目但禁用预览并说明原因。不支持的文件不给编辑器强行解码。 |
| FILE-06 | 标签支持新建、切换、关闭、关闭其他、关闭全部；修改状态可辨。标签主体与关闭按钮命中区分离，关闭不会触发意外切换或关闭相邻标签。 |
| FILE-07 | 切换标签保留内容、选区、滚动位置、编辑模式和撤销历史。最后一个标签关闭后显示无文档状态，仍可新建/打开。自动保留最后使用工作区根及其侧栏/布局偏好（侧栏显隐、宽度、文件/大纲视图）；常规启动恢复一个窗口及这些偏好，不恢复 tabs。显式文件打开仍按 FILE-02～03 处理，不因偏好恢复额外开窗。完整标签会话和最近记录不计入本轮基线，异常恢复独立保留；恢复条目逐文档处理，不提供全部丢弃入口（WC-05）。关闭工作区将待恢复根记为空；未随后使用新工作区时，常规启动保留一个无工作区窗口，不重新打开已关闭根，仍不恢复 tabs（UI-06）。 |
| FILE-08 | 关闭未保存文档、窗口或退出时，逐个标签提供保存、放弃更改、取消。取消或保存失败停止后续批量关闭，并保留当前及尚未处理标签；已明确保存或放弃并关闭的标签不重新打开。图片预览 tab 不产生保存询问。 |

### 5.2 保存、保真与异常恢复

| 编号 | 要求与验收结果 |
|---|---|
| SAFE-01 | V1 只接受有效 UTF-8 Markdown，保留 UTF-8 BOM；其他编码或无效字节明确报错，不静默替换字符，不提供额外编码转换或只读解码入口，不覆盖原文件。 |
| SAFE-02 | 未修改文件保存时逐字节不变，包括 BOM、混合行尾、空白、标记写法及文件末尾是否有换行。打开、阅读、主题切换和模式切换均不构成修改。 |
| SAFE-03 | 局部编辑不重建全文 Markdown。统一行尾文件保留其风格及未编辑部分；混合 LF/CRLF 文件编辑后按多数派统一，数量相同使用 LF，这是保真要求的明确例外。为保留孤立 CR，LF 策略下紧跟在孤立 CR 之后的 CRLF 单元保留 CRLF，结果可以仍含混合行尾。 |
| SAFE-04 | 自动保存默认开启，可在设置关闭；对已有路径且有修改的文档，停止输入 1 秒后防抖保存，中文组合输入未结束时延后。外部冲突或撤销重载后的暂停规则见 SAFE-07。未命名文档只做异常恢复，不自动选择路径。保存包含当前编辑块最新内容。按 ED-01，组合未结束时的显式手动保存/另存为请求进入可取消等待；平台自然确认或取消后取结束后的当前快照，不发布预编辑候选、不强制结束组合。取消保存请求不改变当前输入，取快照不封口输入组或改变历史（EDIT-05/06）。 |
| SAFE-05 | 保存状态至少区分未修改、有修改、保存中、保存失败。只有对应版本写入成功才能显示已保存；保存期间继续输入的内容仍应显示为有修改。撤销回已保存内容时恢复已保存状态。 |
| SAFE-06 | 写入失败、权限错误或磁盘空间不足时保留内存内容，说明失败并允许重试或另存为；权限复制仅在文件系统明确返回 Unsupported/ENOTSUP，且已证明临时文件创建与替换访问语义安全时，才允许继续并说明实际保证；其他权限复制失败必须停止写入并保留原文件字节，不得一概忽略错误。不能用成功提示掩盖失败，也不能留下损坏的原文件（平台证据见 V-01/V-08）。 |
| SAFE-07 | 聚焦时检查外部变化，任何写盘前再检查磁盘版本。本地无修改时自动重载并保持可定位位置；有冲突时暂停自动保存，展示基线/本地/磁盘差异，提供载入磁盘、确认覆盖、另存为、取消，不自动合并。自动重载与“载入磁盘”均建立明确可撤销的历史边界，保留重载前内容及选区；重载后磁盘基线更新，撤销/重做仅改变内存，不回退磁盘基线或直接写盘。撤销带回不同旧内容时标为有修改并提示来源，暂停自动保存以避免自动覆盖当前磁盘；用户显式保存/另存为成功或重做回磁盘基线后恢复正常自动保存策略，再保存仍须检查磁盘版本。文件删除或不可读时保留内存、反馈状态并允许重试/另存为。 |
| SAFE-08 | 有修改的命名及未命名文档每 10 秒保存恢复快照，包含当前输入和临时图片引用。异常记录启动时逐文档提供恢复或丢弃；V1 不提供“全部丢弃”批量入口。恢复先进入内存，不覆盖磁盘。临时图片必须随恢复数据保留；清理遵循第 5.12 节状态表。 |

### 5.3 编辑模式、输入与历史

| 编号 | 要求与验收结果 |
|---|---|
| EDIT-01 | 只有可视化和源码两种编辑模式。两者操作同一份文本、共享同一撤销历史；切换不改字节，不清空历史，并按源码位置恢复光标或选区。 |
| EDIT-02 | 默认可视化模式，未编辑块按内容呈现；除 MD-11 的只读展示区外，点击块就地进入编辑，同一文档至多一个块处于打开编辑状态。提交与关闭编辑块分离：块可保持打开，并按 EDIT-06 输入组提交；点击其他块、失焦或按 Escape 时仅提交剩余未封口组，不重复记步或将已有组压成整块一步；Escape 不丢弃输入。 |
| EDIT-03 | 编辑块内 Markdown 标记低对比度显示，正文、光标和选区清晰；开合不使无关内容明显跳动。折叠标记增强不阻塞基础编辑，不计入本轮发布门禁。 |
| EDIT-04 | 点击展示文字能定位到对应源码位置；转义字符、实体、中文、emoji 和组合字符附近不会错位、拆坏字符或导致错误删除。 |
| EDIT-05 | 中文 IME 的组合、候选、确认、替换及取消正确；组合过程中不触发错误格式命令、预览提交或焦点跳转。一次确认的组合输入可作为一步撤销。 |

### 5.6 Markdown 与 HTML 呈现

| 编号 | 内容 | V1 要求 |
|---|---|---|
| MD-01 | 基础块 | H1–H6、段落、分隔线、围栏及缩进代码块、嵌套引用、有序/无序/任务列表、表格。 |
| MD-02 | 行内 | 粗体、斜体、删除线、行内代码、链接、自动链接、图片、emoji 短代码；脚注引用及定义遵循 MD-11 的只读展示限制。 |
| MD-03 | 提示块 | GitHub Alerts 的 NOTE、TIP、IMPORTANT、WARNING、CAUTION 五类，层级和语义可辨。 |
| MD-04 | 导航 | 大纲根据标题层级跳转；`[toc]` 目录和脚注的基础展示/导航保留，内容放在灰色展示区，不能就地编辑；修改必须切源码。语法与回跳样例由 V-07 固化。V1 大纲仅纳入标题层级与主动跳转，不纳入正文滚动反向高亮、自动展开或揭示当前标题（UI-03）。 |
| MD-05 | 数学与图表 | 行内及块级公式、Mermaid 围栏；行内公式在块打开时显示源码，块公式及 Mermaid 上源码/下预览，300ms 防抖。支持清单以实际渲染覆盖率和错误夹具为准，见 V-03。 |
| MD-06 | Front matter | 文首 `---` 或 `+++` 完整配对围栏作最小识别，忽略 BOM 后判断文首；灰色原文块只读展示，只能源码模式修改，不提供属性面板或完整元数据解析。未闭合围栏不得吞掉整篇。 |
| MD-07 | 行内 HTML | `b/strong`、`i/em`、`s/del/strike`、`u`、`mark`、`code/kbd`、`a` 映射为相应文字样式；实体解码，错误交叉嵌套按限定修复规则处理。链接需有效 `href` 才赋予链接行为。 |
| MD-08 | HTML 块 | 消费普通标签、保留可见文字，应用支持的行内样式，块级标签产生换行，折叠空白，展示时忽略注释，解码实体并识别 emoji 短代码；源码注释仍保留。点击后编辑原始 HTML。 |
| MD-09 | HTML 安全边界 | 不执行脚本，不加载 iframe，不采用网页盒模型。`script/style/iframe/title/textarea/xmp/noembed/noframes/plaintext` 等过滤标签按字面文本显示；任意 HTML/CSS 不承诺等同浏览器呈现。 |
| MD-10 | HTML 编辑边界 | 行内格式或块命令触及 HTML 区域、跨越 HTML 边界时拒绝执行并反馈原因；用户仍可直接改源码。不得为了套格式破坏标签或丢弃不可见源码。 |

MD-11：脚注内容、`[toc]` 目录和 Front matter 使用类似代码块的灰色展示区，保留基础展示语义，但可视化模式中只读，不点击进入就地编辑。脚注引用保留导航，不开放就地格式命令。修改统一切到源码模式；可视化删除、替换或跨块粘贴若触及受保护区域，应拒绝并定位源码，不能绕过保护。其他不支持语法直接显示原文，保存不得删除。

未知语法或不支持的内容必须保留源码并允许在源码模式修改，不能在保存时自动删除。正式验收需要基础语法、列表与引用、代码与表格、公式与图表、图片与 HTML 五组实际 Markdown 夹具，覆盖嵌套、长短内容、空行、错误输入与边界状态。

### 5.8 插件系统与 V1 内置实现

插件系统是 Aline 的核心扩展能力，统一承接能力扩展点、注册、启停与配置。当前先提供六个随应用编译的常用内置插件；它们是系统的首批提供者，不构成封闭的插件种类清单。

后续将支持独立分发、在应用编译之外加载的外部插件，新增插件不需要重新编译应用。加载协议、执行环境、隔离与权限、兼容规则和交付阶段尚未确定，须后续设计；当前没有据此把外部加载纳入 V1，V1 仍不提供第三方插件安装、商店或运行时加载。

六内置插件默认开启，可独立关闭；图片预览是本轮新增能力。以下只规定本期六个内置实现的产品行为。

| 插件/编号 | 启用时 | 关闭或失败时 |
|---|---|---|
| Mermaid · PLUGIN-01 | 图表预览、复制、SVG/PNG 导出；跟随应用明暗或固定内置/自定义图表主题，支持导入与管理 | 关闭后展示源码，隐藏预览、复制图表和图表导出命令；SVG/PNG 导出和图像复制仅由本插件开关控制，不受导出插件开关影响（PL-01）；失败保留源码和错误状态 |
| 表格增强 · PLUGIN-02 | 提供行列边界悬停插入按钮；无独立配置分区 | 关闭后保留核心表格能力，见 EDIT-14 |
| 导出 · PLUGIN-03 | 工具栏和菜单提供 PDF、Word、HTML 导出 | 关闭后仅隐藏两处三格式正文导出入口；不隐藏或取消 Mermaid 独立 SVG/PNG 导出及图像复制，已编辑文档不受影响（PL-01） |
| 公式 · PLUGIN-04 | 行内/块级公式渲染，背景可随内容主题、透明或自定义 | 关闭时显示公式源码；失败显示错误且允许继续编辑 |
| 代码语言高亮 · PLUGIN-05 | 编程语言语法着色，主题和模式独立选择，源码模式代码围栏复用该能力 | 关闭、未知语言或失败时显示普通代码；关闭时背景、文字和行号使用当前内容主题普通代码样式，独立代码主题/模式配置保留但暂停作用，再启用恢复；行号、复制、语言选择和编辑保留（PL-02） |
| 图片预览 · PLUGIN-09 | 图片作为只读 tab 打开，支持适应窗口、1:1、缩放和平移 | 关闭时禁用图片 tab 预览，图片仍可在 Markdown 中显示；当前预览退出为说明状态，不强行关闭文档。再启用时自动恢复仍打开标签；适应模式按当前视口重算，手动缩放恢复原缩放并约束平移；资源变化或失败说明原因并保留路径（PL-03）。不因此恢复重启前 tabs |

PLUGIN-06：开关和配置持久化，运行时生效；关闭时保留配置，隐藏对应插件设置导航与内容，重新启用恢复。图片预览启停对已开 tab 的视口恢复依 PL-03；图片 tab 状态不持久化为重启会话。插件开关只出现在“应用设置 > 插件”，专属配置不能重复放开关。某插件无配置时不制造空设置页。

PLUGIN-07：Mermaid 主题只影响图表，固定主题不受应用变化覆盖；跟随只读取明暗，护眼映射亮色，不继承界面强调色。自定义主题采用经校验的静态数据；具体格式、管理动作和图类型支持清单由 V-03 冻结。

PLUGIN-08：代码主题和代码高亮模式分别支持“随应用”与“固定”。例如 GitHub 白天界面可搭配 Vue 暗色代码；背景、文字、行号和语法色一同切换，字体、行高和布局仍来自 Markdown 主题。固定的维度不被应用主题变化覆盖。关闭高亮时使用当前内容主题的普通代码背景、文字和行号，独立主题/模式保留但暂停作用；再启用按当前有效配置恢复（PL-02）。

### 5.11 设置与多语言

APP-01：设置是单一连续纵向滚动页面，固定侧栏分“应用设置”和“插件设置”。点击导航滚到分区，手动滚动同步选中态与位置标题，不以分类切换整页内容。 按 UI-01，设置为当前主窗口内页面，提供返回编辑入口，返回恢复原文档/标签及编辑上下文；不创建独立设置窗口或模态设置弹窗。

APP-02：应用设置按通用、外观、编辑器、图片、高级、插件排列；插件专属分区随后，代码语言高亮位于整个内容底部。快捷键一览和关于使用独立弹窗。编辑器设置提供正文/源码自动换行、代码块自动换行；代码行号常显。不提供打字机、拼写检查或 PlantUML 设置；原型的其他未立项开关不进入产品。

APP-03：外观按模式、字体与排版、界面、主题配置排列；主题配置位于外观分区最下方。主题卡片显示当前模式的真实预览、名称、内置/已导入状态和最多五行介绍，悬停或键盘聚焦可查看完整介绍。大图可用左右按钮或方向键切换三模式。 按 UI-02，标题/名称按钮立即应用主题，缩略图独立按钮打开大图，两者名称与键盘焦点独立；浏览大图或切换预览模式不应用主题。

APP-04：首发 zh-CN 和 en，默认跟随系统语言，并允许设置覆盖。所有菜单、错误、插件、设置和提示均翻译；内容及文件名不自动翻译。用户切换语言即时生效，保持当前编辑状态。

APP-05：有效设置持久化，错误值不得导致启动失败；不能显示与实际行为不一致的开关或成功提示。设置全应用共享、窗口布局独立；工作区偏好按 FILE-07 自动保留并以常规单窗口恢复，不恢复完整标签会话；用户显式字号/行高优先于主题，分区重置仅清除该分区覆盖。默认值见第 5.13 节。

APP-06：提供按诊断类别去重的会话级内存降级汇总，由 UI 呈现。汇总明确归属当前应用会话、文档身份及文档版本；文档关闭时释放所属条目，会话关闭时释放集合，文档版本更新后不回填或显示旧版本结果。汇总有容量上限，不持久化正文、IME 候选文本或敏感路径，不使用引擎 thread-local。容量数值和呈现布局由 V-06/V-09 验证确定，不在本稿预设。

### 5.12 本轮确定的操作契约

FORMAT-01：V1 提供全文 Markdown 格式化，唯一触发入口放在菜单栏“编辑 > 格式化 Markdown”。只能由用户手动触发；保存、自动保存、打开、模式切换和粘贴均不触发。

FORMAT-02：执行前显示差异，确认后一次应用、一步撤销；取消不改内容。未知语法、HTML 和原文保留区域不被擅自重写。文件整体不可安全格式化时明确拒绝，不丢失内容；具体风格和保护样例由 V-07 冻结。

FILE-09：文件树支持将文件拖到工作区内目标文件夹以移动；显示可放置目标，无效目标不执行。重名或冲突先提示，不静默覆盖。目录拖动以同一规则处理，并拒绝移入自身/后代。移动同步所有打开标签路径、工作区状态和图片预览；移动/重命名导致相对资源引用变化时先展示影响，不假定引用仍有效。跨卷/外部拖放的支持边界由 V-08 样例明确。 按 UI-05，文件/目录目标菜单同时提供键盘可达的“移动到…”目标选择入口，复用拖动的工作区内目标校验、冲突/资源影响提示与路径同步；取消不移动，不新增文件剪切/粘贴移动或跨工作区范围。

IMAGE-07：未命名文档允许插图。先将资源写入该文档独立临时目录，保存临时引用并可正常展示；首次保存获得 Markdown 路径后，按图片设置计算目标目录、避免重名，复制所需图片并更新引用，再保存文档。保存失败/取消保留内存、临时图片和恢复记录，不生成损坏文档；成功后也不能删掉仍被撤销或恢复历史引用的资源。

IMAGE-08：已命名文档另存为时，保证应用管理的图片在新路径仍可访问；相对资源目录按新文档位置解析，需要时复制资源并重写引用，绝对资源目录保持原目标。原文档和原资源保留。对仅手写引用的外部资源不静默移动，失效风险明确提示；迁移和清理用例由 V-08 固化。撤销图片插入只撤销引用，不自动删除已写资源。

恢复记录使用稳定文档身份，不单靠文件名；路径变更更新关联关系。清理规则如下，具体事务和原子性由实现设计保证：

| 场景 | 恢复记录与临时图片处理 |
|---|---|
| 未命名且有修改 | 每 10 秒更新快照，保留临时资源；不自动保存到用户文件路径 |
| 保存取消/失败 | 保留全部恢复材料，不标记保存成功 |
| 保存成功但文档仍打开 | 可将对应版本标为已保存；仍有更新或历史引用的临时资源不得删除 |
| 用户正常关闭且保存成功 | 清理已落盘且无其他引用的恢复快照/临时资源 |
| 用户逐 tab 明确放弃更改 | 只清理该文档不再使用的恢复记录/临时资源，继续下一 tab |
| 关闭时取消 | 保留当前及未处理文档的全部状态和恢复材料 |
| 异常退出或恢复后尚未保存 | 保留恢复记录和图片，直到后续保存并正常关闭或明确丢弃 |
| 文件重命名/移动 | 更新身份到路径的关联；旧路径不生成可覆盖其他文件的恢复副本 |

PREVIEW-01：图片预览插件开启时，从文件树/打开命令选择本地图片，在主内容区打开只读图片 tab。与 Markdown 共用标签栏，同一路径复用已有 tab，切换不影响其他文档编辑状态。

PREVIEW-02：默认适应窗口且不放大小图，提供缩小、放大、适应窗口、原始尺寸（1:1）及百分比。手动缩放采用 1.25 倍步进、范围 10%–800%；适应模式随视口变化重算。

PREVIEW-03：图片超出视口可按住鼠标左键拖动平移；正常滚动可用。第一版不额外引入滚轮缩放手势，避免与滚动冲突。核心按钮可键盘聚焦执行。

PREVIEW-04：加载失败在预览区显示错误占位，保留 tab 与路径；图片不产生未保存状态，关闭不弹保存确认。预览不编辑图片像素。插件关闭不关闭其他文档，也不影响正文内嵌图片。关闭期间保留仍打开图片 tab 的适应/手动模式和视口状态；再启用自动恢复，适应模式按当前视口重算且不放大小图，手动模式在当前文件/视口约束下恢复原缩放并约束平移。资源变化/失败说明并保留路径；不恢复已关闭 tab 或常规重启前 tabs（PL-03）。

## 6. 界面与交互基线

### 6.1 主窗口与导航

采用桌面文档编辑器布局：系统菜单及窗口栏、工具栏、多文档标签、左侧文件/大纲侧栏、中央编辑区、底部状态栏。侧栏可开关和拖宽；文档编辑是主要视觉区域。应用名称与身份统一使用 Aline。

应用身份采用用户提供并已裁切的象牙色圆角底板、炭灰 A 与金色丝带图标，资源统一来自 [应用图标目录](./assets/app-icon/README.md)。macOS 应用包使用 `aline.icns`，Windows 可执行文件与快捷方式使用 `aline.ico`，应用内品牌展示及 Linux 图标使用透明 `aline.png`。保留底板，底板外透明，不出现外部白底或白边；原图和预览不作为运行时图标。旧品牌 PNG 及原型内副本按用户要求删除，历史哈希仅供追溯；选图已确定，打包接入与三平台实际显示仍按 V-01 验证。

- 标签过多时内容横向滚动且不显示滚动条；新建和标签列表按钮固定在右侧。当前、悬停或键盘聚焦的标签显示关闭按钮；悬停关闭按钮出现浅色圆底。
- 标签下拉列表顶部固定“全部关闭”，文档条目区域独立滚动。“全部关闭”下方保留一条横向分隔线。
- 文件树顶部固定显示工作区文件夹名，不提供根目录折叠按钮；悬停或键盘聚焦该区域显示新建文件、新建文件夹、刷新、展开/收起子目录四个按钮。只要有子目录展开，批量操作即显示“收起”；全部收起时显示“展开”。
- 源码与可视化模式共用内容列宽和主滚动条位置；源码区不另加纵向滚动入口。切换按文档位置定位，不能机械复用像素值导致跳到无关内容。
- 状态栏提供模式状态、外观模式和快速主题入口；快速选择与设置页共享状态。统计在可视化和源码模式保持统一口径；中文、英文、标记、代码、选区和光标字符计数样例在 V-07 中冻结，不能用字节数冒充用户可见列数。

### 6.2 浅色样式与代码块

默认 GitHub 浅色主题使用素白编辑画布和中性色，蓝色表达交互。基准色为画布 `#FFFFFF`、正文 `#1F2328`、次级文字 `#59636E`、边框 `#D1D9E0`、强调 `#0969DA`、代码底色 `#F6F8FA`；其他主题允许使用各自配色。

- 围栏与缩进代码块使用相同外观与控件。行号从 1 开始，空行计数，软换行不重复编号；代码与行号逐行基线对齐，行号作为基线能力保留。
- 悬停或键盘聚焦时，语言和复制控件贴在代码块右上方，不额外增加标题栏。语言菜单贴按钮下沿、紧凑且可搜索；未知语言按纯文本显示。
- 更改语言仅修改语言标识，不改变代码正文；缩进代码块设置语言时允许转成围栏块，保持代码正文并可一步撤销。
- 复制只含代码正文，成功后按钮显示勾号约 2 秒，不额外弹 toast。失败时不能显示成功状态。
- 代码块内部可滚动但隐藏内部滚动条的视觉；滚动目标与键盘操作可用，不能与主文档滚动互相阻断。

### 6.3 菜单、键盘与反馈

- macOS 使用系统菜单：Aline、文件、编辑、插入、格式、视图、主题、窗口、帮助；设置、关于、退出按系统惯例归入 Aline 菜单。
- Windows/Linux 使用对应桌面菜单及窗口控制：文件、编辑、插入、格式、视图、主题、窗口、帮助；设置/退出在文件菜单，关于在帮助菜单。
- 主题独立成菜单，模式与家族分组；各入口选中态一致。操作依赖文档、选区或插件时，启用状态随之变化。V1 范围外项隐藏；当前状态不可用项置灰并解释原因。
- 右键菜单按文本、源码、标签、文件树、表格、图片、图表区分对象；一次只显示一个菜单，靠边自动避让。Escape、点击外部或执行命令后关闭；键盘可导航、展开子菜单和执行。
- 主要流程可用键盘完成，焦点清晰，图标有可理解的名称；不能只靠颜色区分修改、错误或危险操作。中文与英文下不裁掉关键按钮文字。
- 快捷键按平台使用 Cmd 或 Ctrl，并在菜单和一览中一致展示。危险文件操作需明确确认；正文编辑误操作以撤销恢复。
- 按已确认 UI-04，菜单分组、工具栏编排及首批键位采用[UI 规范 §10.5](./ui-spec.md#105-菜单与工具栏编排基线ui-04-已确认)：新建 N、打开 O、保存 S、另存为 Shift+S、关闭当前标签 W、撤销 Z、重做 Shift+Z、剪切/复制/粘贴 X/C/V、纯文本粘贴 Shift+V、全选 A、查找 F、粗体 B、斜体 I、链接 K 均加平台 Cmd/Ctrl；设置 Cmd/Ctrl+,，macOS 退出 Cmd+Q。未分配直接键位的操作仍可经键盘菜单访问；格式化仍只有编辑菜单入口。工具栏按侧栏、编辑模式、行内格式、段落/插入、导出、设置分组，窄窗保留可达溢出入口。实际系统冲突和布局继续验 V-01/V-09，不静默改变绑定。

## 7. 非功能需求与质量门禁

### 7.1 平台与本地能力

正式 V1 在 macOS、Windows、Linux 三平台一起发布。先完成 macOS 验证，再开展 Windows/Linux 验证；三者发布门禁均通过后发布正式 V1。Windows 10 和 Intel Mac 保留为必须支持目标，最低环境、架构和安装/关联矩阵在 V-01 中验证并固化。内部预览不代替三平台正式验收。

本地打开、编辑、保存、图片、公式、Mermaid、主题和导出不依赖账号或云服务。V1 不接入 AI，不上传文档内容；系统打开外部链接是用户明确发起的独立操作。

### 7.2 性能目标

以下为既有性能目标，不是当前实测成绩。计时边界、分位数和设备矩阵按 V-05 实测后形成发布门禁；引擎耗时不能代替端到端体验指标。

| 场景 | 基线目标 |
|---|---|
| ≤32 KiB 典型文档 | 块提交处理 <10ms |
| ≤128 KiB 日常文档 | 块提交处理 <50ms；日常输入、查找、切换块无明显卡顿 |
| 可视化块内输入 | 文本处理预算 <1ms/键；需另测到屏幕呈现的完整延迟 |
| 1 MiB 级文档 | 编辑与滚动保持可交互，后台结果不覆盖更新后的内容 |
| >4 MiB 文档 | 默认自动使用源码模式并提示原因；阈值可配置 |
| 4 MiB 源码输入 | 文本处理预算 <4ms/键；不得以主线程长时间无响应满足降级 |
| 图片、公式、图表 | 加载和渲染不阻塞输入；失败及过期结果不破坏文档状态 |

文件大小不能独自代表复杂度；长段落、巨型表格、大量图片及错误公式/图表需单独验收。超过资源上限时应明确降级或拒绝，仍保留文件和源码，不崩溃或静默截断；只接受有效 UTF-8、混合行尾平票 LF 已确定；文件/资源限额经 V-06 实测冻结。

### 7.3 发布验收场景

| 编号 | 场景 | 通过条件 | 对应需求 |
|---|---|---|---|
| AC-01 | 打开后不编辑，保存并比较字节 | BOM、混合行尾、空白及无末尾换行均不变 | SAFE-01～03 |

## 8. V1 不纳入范围

- 协同编辑、云同步、账户体系、AI 服务与 AI 自动修改文档。
- V1 暂不交付运行时第三方插件加载、插件商店、用户可执行脚本。外部插件接入是已明确的后续方向，插件系统本身须可扩展，不把本期内置范围当成永久限制。
- PlantUML、Draw.io 等额外图表引擎；预留接口不构成交付承诺。
- 远程图片请求/下载、图床上传。
- Front matter 属性面板、完整字段解析和元数据工作流；脚注、目录、Front matter 的可视化就地编辑不提供，保留灰色只读展示及源码编辑。
- Markdown 独立只读/Preview 模式、Split 分屏；可视化模式兼顾阅读，图片只读 tab 属于单独的图片预览插件。
- 纯文本导出、完整浏览器 HTML/CSS/JavaScript 渲染。
- 移动端、多光标、Vim 模式、源码 minimap 和代码折叠等 IDE 能力。
- 全标记隐藏编辑器、打字机模式、拼写检查；折叠标记增强不计入基线。Markdown 格式化已纳入 V1，仅允许菜单手动触发。
